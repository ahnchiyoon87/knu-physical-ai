# 경남대 피지컬 AI 리뉴얼 · 현재 인계

2026-09-14 갱신. **전체 목표는 진행 중이다.** 현재 제작본과 실제 미결을 아래에 구분한다. 이전 인계의 누적 진행 기록은 Git `ae1202b`에서 보존되며 현재 상태로 사용하지 않는다.

## 요청과 일정

- 상세 Markdown 이론 덱, 온라인 이론 대본, 순서대로 읽는 실습가이드, 신규 코드·이전 단계 출발본·일차별 완성본을 모두 준비한다. PPTX는 사용자가 NotebookLM으로 제작한다.
- 실전반=4학년, 통합반=2·3학년이다. 원본 엑셀에서 확인했다. 두 반의 내용은 같고 회차별 묶음만 다르다. 대본은 온라인 이론에만 작성한다.
- 원본 영상은 실전 8편/32H, 통합 11편/44H다. 실습은 9일/36H와 10일/40H, 합동 OT 실제 2H다. 영상 시수와 실습 시수를 합쳐 분량 충족을 주장하지 않는다.
- 학생이 자기 서비스를 만들도록 돕고 같은 결과를 강제하지 않는다. 감시·의무 회고·미시청자 제한은 추가하지 않는다.
- 현재 모델·DB 업무·GPU·유료 호출·학생 실습 완주를 실행하지 않는다. 실행 제외는 내용·코드 제작을 생략하는 이유가 아니다.

기존 `이론덱`, `대본`, `학생가이드`의 반별 일차 자료와 과거 ZIP은 제작 기록이다. 공통 자료와 혼용하지 않는다. 기존 학생가이드 아래의 OT·실행 연결·질문 자료는 현재 공통 자료에서도 연결해 사용한다. 파일 수는 내용·시간 충족의 증거가 아니다.

현재 이론 순서는 AB(뜻·품질) → CF(시각화·표 판별) → DH(규칙·시계열) → EN(파이프라인·비교) → GI(이미지·수명) → J(RAG) → KL(평가·배포) → OP(도구·폐루프)다. M은 O/P의 기존 중복 묶음이다. 통합 영상은 공통 5·7·8단위를 각각 둘로 나눈다. EN을 4단위로 옮겨 실전 4일차보다 이론 공개가 늦던 문제를 해결했다.

## 편집과 공유

공통 집필 원천은 `20_도구/build_common_course.py`가 읽는 기존 덱·대본과 `common_course_editorial.py`, `common_worked_examples.py`다. 현재 RAG에 단일 질문을 끝까지 추적하는 12장 사례를 추가했다. A(데이터 뜻)의 적용 18장도 실제 표의 계산·연결·값 표기·관계 해석을 설명하는 독립 발화로 교체해 두 반 화면/대본 36개씩에 반영했다. 근거는 `30_기록/기초데이터적용_대조.json`이다. 기존 관리 파일을 수정한 뒤 생성기를 무조건 실행하지 않는다. 해시·입력 변경을 먼저 확인하고 영향받는 공통 원고→영상별 제작본→연결 학생 ZIP만 갱신한다. 실습 변경은 `common_lab_plan.py`의 단계와 출발·완성 패키지까지 연결한다.

`refresh_current_docs.py`, `build_index.py`에는 과거 상태 문장이 남아 있어 현재 문서에 그대로 실행하면 안 된다. 자산 생성 소스는 현재 자산과 내용 대조를 마쳤지만 직접 실행 시 편집 보호 보완이 남아 있다. 앱 편집 전 앱의 AGENTS.md와 constitution.md를 읽는다.

사용자가 전체 자료의 Git 공유를 승인했다. 저장소는 https://github.com/ahnchiyoon87/knu-physical-ai.git 의 `main`이다. 현재 Git/원격을 확인하고 커밋·push한다. `.env`·자격증명·로컬 실행 환경은 제외하고 예시 설정·원자료·제작 기록은 포함한다. Google Drive 업로드나 ESNS 메시지는 아직 수행하지 않았다.

전체 요청을 실제로 마친 뒤 STUDY의 기존 최종 보고서 하나를 전체 범위로 갱신한다. 저장소 `30_기록/이전작업보고`의 덱 단계 보고는 과거 기록이다. 중간 보고를 추가하거나 전체 목표를 먼저 완료로 바꾸지 않는다.
