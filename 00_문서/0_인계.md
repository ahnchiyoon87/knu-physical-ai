## 최신 방향 — 대표님 플랫폼을 베이스로 채택

최신 운영 방향: 중앙 서버 비용 최소화 요청에 따라 **학생별 로컬 플랫폼·DB·시뮬레이터 + 중앙 모델 중계**를 기본 설계로 기록했다. 코딩 에이전트가 설치·MCP·코드 설정을 수행한다. 원천 Compose에 네 서비스가 있으나 개인 PC 사양·초기화·데이터 마운트·중계 호환성은 미검증이다. 강사 공통 실습 서버를 필수 인프라로 확정하지 않는다. 자세한 범위는 채택 문서의 ‘운영 방향 추가’ 참조.

후속 확정: 대표님 **냉각 이상 대응을 공통 학습 시나리오로 유지**하고, 우리 실제 제조 데이터는 후반 확장 PBL에 녹인다. 초반부터 우리 시나리오로 바꾸는 아래의 이전 제안은 대체됐다. 비전공자에게 제공 명세·AI 요청 예시로 시작해 도움을 점차 줄이는 SDD/AI 코딩을 적용한다. ‘대표님 그대로 복제’와 ‘기존 리뉴얼 전체 재사용’ 모두 아니다. 최신 세부 기준은 채택 범위 문서 첫 절을 읽는다. ‘참고’의 폴더 지칭 여부 확인 중이며 새 폴더·플랫폼 이식은 아직 미실행이다.

사용자는 대표님 저장소를 참고만 하는 방식에서 **플랫폼·UI를 베이스로 우리 강의를 개편**하는 방향으로 바꿨다. [HydOps 베이스 채택 범위](검토/HydOps_베이스_채택범위.md)가 현재 설계 판단이다. 사용자 클론 `D:/work/study/lecture-manufacturing-physical-ai-platform`의 HEAD는 `5bd83e810631107502c54d930dfe0edef395dd6b`이며 앞서 검토한 HydOps와 같다. 사용자 클론은 변경하지 않았다.

- Data Fabric·Ontology Studio·Agents·Processes·Apps와 운영 UI를 채택하고 우리 데이터/관계/도구/업무 정의를 연결한다. 기존 equipment-assistant 중심의 일괄 추가 제작은 중단한다. 학교 날짜·시수·반 구성과 같은 핵심 내용, 온라인 이론만 대본이라는 조건은 유지한다. 엑셀의 주제와 순서는 고정 틀이 아니다.

## 요청과 일정

- 상세 Markdown 이론 덱, 온라인 이론 대본, 순서대로 읽는 실습가이드, 신규 코드·이전 단계 출발본·일차별 완성본을 모두 준비한다. PPTX는 사용자가 NotebookLM으로 제작한다.
- 실전반=4학년, 통합반=2·3학년이다. 원본 엑셀에서 확인했다. 두 반의 핵심 내용은 같고 엑셀의 회차·시수에 맞춰 설명·사례·복습 분량을 구성한다. 대본은 온라인 이론에만 작성한다.
- 사용자가 엑셀대로 진행하도록 재확인했다. 원본 영상은 실전 8편/32H, 통합 11편/44H다. 실습은 9일/36H와 10일/40H, 합동 OT 실제 2H다. 영상 시수와 실습 시수를 합쳐 분량 충족을 주장하지 않는다.
- 학생이 자기 서비스를 만들도록 돕고 같은 결과를 강제하지 않는다. 감시·의무 회고·미시청자 제한은 추가하지 않는다.
- 현재 모델·DB 업무·GPU·유료 호출·학생 실습 완주를 실행하지 않는다. 실행 제외는 내용·코드 제작을 생략하는 이유가 아니다.

## 편집과 공유

공통 집필 원천은 `20_도구/build_common_course.py`가 읽는 기존 덱·대본과 `common_course_editorial.py`, `common_worked_examples.py`다. RAG의 연속 사례 12장과 주제 경계 설명을 보존한다. `narration_application.py`에는 공통 15개 주제의 적용 장면 각18개, 총270개의 별도 발화와 화면 핵심 문구가 있다. A~I와 L/N의 반복 템플릿도 교체했다. [전체 적용 대조](../30_기록/전체적용대본_대조.json)는 공통 원고와 두 반 영상별 제작본에 모든 문구가 반영됐음을 확인한다. 공통본의 ‘다음 영상→다음 구간’ 편집 변환도 기대 본문에 반영했다. 주제별 의미 검토 범위는 각 `…적용_대조.json`에 기록했으며 전체 강의 의미·시간 검토를 대신하지 않는다.

`check_common_packages.py`로 현재 38개 코드 ZIP의 재추출·API import·분류 단계·CSV 줄바꿈·코드 연속성을 검사할 수 있다. `build_checkpoints.put`은 CSV의 CRLF를 다시 변환하지 않도록 수정했다.

현재 관리 파일을 수정한 뒤 생성기를 무조건 실행하지 않는다. 해시·입력 변경을 먼저 확인하고 영향받는 공통 원고→영상별 제작본→연결 학생 ZIP을 갱신한다. 실습 변경은 `common_lab_plan.py`의 단계와 출발·완성 패키지까지 연결한다.

`refresh_current_docs.py`, `build_index.py`에는 과거 상태 문장이 남아 있어 현재 문서에 그대로 실행하면 안 된다. 자산 생성 소스는 현재 자산과 내용 대조를 마쳤지만 직접 실행 시 편집 보호 보완이 남아 있다. 앱 편집 전 앱의 AGENTS.md와 constitution.md를 읽는다.

사용자가 전체 자료의 Git 공유를 승인했다. 저장소는 https://github.com/ahnchiyoon87/knu-physical-ai.git 의 `main`이다. 현재 Git/원격을 확인하고 커밋·push한다. `.env`·자격증명·로컬 실행 환경은 제외하고 예시 설정·원자료·제작 기록은 포함한다. Google Drive 업로드나 ESNS 메시지는 아직 수행하지 않았다.

전체 요청을 실제로 마친 뒤 STUDY의 기존 최종 보고서 하나를 전체 범위로 갱신한다. 저장소 `30_기록/이전작업보고`의 덱 단계 보고는 과거 기록이다. 중간 보고를 추가하거나 전체 목표를 먼저 완료로 바꾸지 않는다.
