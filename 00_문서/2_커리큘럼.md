## 한 실습일의 운영 틀

4H 안에서 출발 20분, 실습 블록 네 개 각 50분, 마무리 20분을 설계 기준으로 둔다. 블록에는 필요한 설명·실행 대기·문제 해결을 포함한다. 학생 소요시간 실측은 하지 않았다. 별도 영상 과제 리뷰 30분을 추가해 270분으로 만들지 않는다.

가이드는 그 자리에서 배경 한두 문장 → 필요한 입력 → 학생이 정할 문제 → 짧은 힌트 → 관찰할 결과 → 다음 행동으로 흐른다. 일차 중간에 별도 긴 이론 시간을 끼워 넣지 않는다. 개인 노트 분량·비교 회고 제출·미시청자 참여 제한을 새로 요구하지 않는다.

## 진도 경계를 주의할 곳

- 통2는 실전반의 품질·시각화 회차를 거치지 않았다. 출발본의 추가 기능을 짧게 이해할 수 있는 설명을 가이드 안에 넣는다. 학습하지 않은 상태를 이미 배웠다고 가정하지 않는다.
- 통4는 시간·샷 기준과 규칙 감지의 전제를 출발 자료에서 확인한다. 실전반과 같은 코드 상태라도 필요한 배경 설명은 통합반 현재 진도에 맞춘다.
- 통9에서 아직 구현되지 않은 승인 대기의 보존 검사를 완료했다고 하지 않는다. 현재 기능의 배포를 확인하고 승인 흐름은 통10 구현·재배포에서 확인한다.
- 통10은 도구와 폐루프를 하루에 연결한다. 영상10·11의 내용과 현재 상태를 가이드에서 다시 짧게 설명하며 전체 최종 코드를 미리 복제시키는 활동으로 바꾸지 않는다.
- 실9의 확장 시야에는 대규모 검색의 HyDE(가설 답변을 이용한 검색), PRF(초기 검색 결과를 이용한 질의 보강), 관계·외래키 확장 등의 목적을 비교하는 설명을 후속 추가할 수 있다. 현재 원고가 해당 장치를 구현하거나 검증했다는 뜻은 아니다.

## 전달과 후속 제작

학생 안내는 ESNS와 Google Drive의 해당 일차 링크를 기준으로 설계한다. 이론 영상의 원본 배포일은 엑셀대로 보존하며, 전체 실습 코드·정답을 미리 공개하는 방식은 사용하지 않는다. 학교 이수 기록과 자료 전달의 세부 운영은 실제 배포 전 확인할 항목으로 남긴다.

지금 완료한 것은 [이론 덱](이론덱/README.md)이다. 설치 PDF는 보존했으며 신규 실행 가이드·코드·완성본·출발본·배포 링크·낭독 대본·녹화는 후속 작업이다.
