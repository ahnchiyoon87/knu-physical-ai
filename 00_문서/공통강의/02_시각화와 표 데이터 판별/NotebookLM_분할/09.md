# 시각화와 표 데이터 판별 · 공통 이론 덱

실전반(4학년)과 통합반이 함께 사용하는 내용입니다.

제작 상태: 공통 내용 집필본. 회차별 시간 배분과 전체 흐름을 검토 중입니다. 표시한 장수는 녹화 분량의 증거가 아닙니다.

삽화는 해당 장의 대상·관계·조건을 정확히 보여 주는 독창적인 장면으로 제작합니다. 아래 지시는 실제 사진이나 실측 화면의 증거가 아닙니다. 표지나 중복 목차를 임의 추가하지 않습니다.

## U02-S097 · 새 제품에서 결과가 달라집니다

**화면 문구**

기존 제품에서는 성능이 높지만 새 제품의 센서 값 범위는 크게 다릅니다.

기존 모델을 그대로 자동 판정에 넣기 전에 무엇을 할까요?

**삽화·구성** 교육용 사례의 구체적 업무 삽화: 기존 제품에서는 성능이 높지만 새 제품의 센서 값 범위는 크게 다릅니다. 비교에 필요한 기록과 조건만 넣는다. 회사명·인물명·실제 성능을 만들지 않는다.

**이 장의 결론** 기존 모델을 그대로 자동 판정에 넣기 전에 무엇을 할까요?

**다음 장 연결** 선택한 이유를 자료와 연결해 확인하겠습니다.

**근거·성격** 교육용 가정

## U02-S098 · 새 제품의 입력·라벨 의미·분포를 확인하고 독립 평가합니다

**화면 문구**

새 제품의 입력·라벨 의미·분포를 확인하고 독립 평가합니다. 사용 범위 밖이면 보류나 재검사 흐름을 둡니다.

다른 선택을 했다면, 그 선택이 성립하려면 어떤 추가 조건이 필요한지 확인합니다.

**삽화·구성** 이전 문제 장을 복제하지 않고 판단의 결정적 근거를 확대한다. 새 제품의 입력·라벨 의미·분포를 확인하고 독립 평가합니다. 사용 범위 밖이면 보류나 재검사 흐름을 둡니다. 문장은 독립된 큰 텍스트로, 삽화는 근거의 위치를 설명한다.

**이 장의 결론** 새 제품의 입력·라벨 의미·분포를 확인하고 독립 평가합니다

**다음 장 연결** 새 제품의 입력·라벨 의미·분포를 확인하고 독립 평가합니다 다음에는 확인한 결과를 다음 판단에 넘깁니다로 이어갑니다.

**근거·성격** 교육용 해설

## U02-S099 · 확인한 결과를 다음 판단에 넘깁니다

**화면 문구**

같은 근거에서 차트와 설명을 만들고 판별 모델의 입력과 정답을 구별합니다.

개별 결과를 판별했으니 시간에 따라 달라지는 값을 살펴보겠습니다.

**삽화·구성** 앞 장면에서 확인한 기록과 다음 작업에 넘길 근거를 구체적인 문서와 화면으로 연결한다. 확인되지 않은 칸은 임의로 채우지 않는다.

**이 장의 결론** 개별 결과를 판별했으니 시간에 따라 달라지는 값을 살펴보겠습니다.
