# 두 반 공통 내용 전환 기준

실전반은 4학년, 통합반은 2·3학년이다. 사용자의 최신 지시는 두 반의 내용을 같게 하는 것이다. 난이도나 주제를 학년에 따라 나누지 않는다. 대본은 온라인 이론에만 붙인다.

이 문서는 기존 반별 제작물을 공통 내용으로 바꾸는 제작 기준이다. 아래 구성을 실제 덱·대본·가이드·코드·출발본에 적용하기 전까지 공통화가 완료됐다고 표시하지 않는다.

## 공통으로 가르칠 내용

| 공통 단위 | 양쪽 학생이 수행할 일 | 기존 제작 소스 | 확인할 결과 |
|---|---|---|---|
| 1. 데이터를 읽고 뜻을 확인한다 | 표·열·원천·LOT를 구별하고 품질 표시를 붙여 우리말 질문의 계산을 확인한다 | A·B | 같은 평균의 집계 차이, 범주값, 단위와 누락을 설명한다 |
| 2. 결과를 보여 주고 판별한다 | 집계·차트·설명문을 연결하고 라벨이 있는 표에서 판별기를 만든다 | C·F | 화면의 수치와 근거가 맞고 정답 누수·분할·평가 분모를 구별한다 |
| 3. 시간에 따른 변화를 찾는다 | 조건별 규칙과 상대 변화·복합 조건을 적용하고 시계열 기준 구간을 비교한다 | D·H | 감지와 원인 확정을 구별하며 입력 단위·시간·조건 전환을 설명한다 |
| 4. 모델을 서비스로 연결한다 | 적재·감지·예측·저장 흐름을 연결하고 기준선과 모델 변경을 비교한다 | E·N | 중복 입력·단계 실패·출력 계약을 처리하고 품질·지연·비용을 같은 조건으로 비교한다 |
| 5. 이미지와 수명 질문을 다룬다 | 이미지 이상 판별과 남은 수명·기준 도달 예측을 각 자료에 맞게 적용한다 | G·I | 이미지와 센서의 임의 연결을 만들지 않고 종료 사건·구간·단위를 구별한다 |
| 6. 문서와 관계를 근거로 답한다 | 문서 추출·청킹·혼합 검색·재순위화·그래프 연결을 구현한다 | J | 주장과 인용이 연결되고 관련 관계를 사건의 원인으로 바꾸지 않는다 |
| 7. 답을 평가하고 서비스 환경을 옮긴다 | 질문셋으로 근거와 답을 평가하고 클라우드 연결·저장·로그·권한을 구성한다 | K·L | 평가 범위와 배포 환경의 대표 행동을 확인하며 실행하지 않은 결과를 꾸미지 않는다 |
| 8. 제안과 승인을 재관측으로 연결한다 | 도구·상태·제안·승인·결정·재생 비교를 연결하고 다른 주제로 옮긴다 | O·P, 기존 M의 연결 사례 | 승인 대상과 실행 내용이 같고 재관측의 의미와 미확인 기록이 유지된다 |

표의 두 주제를 묶었다고 각 주제의 설명과 실습을 생략하지 않는다. 이미지와 RUL처럼 입력이 다른 기능은 별도 사례로 진행하고 한 설비의 실제 사건인 것처럼 합치지 않는다. 기업/다른 주제로 옮기는 활동도 양쪽 학생에게 제공한다.

## 일정과 공통 내용의 관계

원본 엑셀은 실전반 온라인 8편·32H, 통합반 11편·44H와 서로 다른 실습 일정을 갖는다. 이 값은 영상 제작 시수이며 오프라인 실습 시수와 별개다. 두 반의 내용이 같다는 지시를 시간표까지 같은 것으로 해석하지 않는다.

공통 단위는 내용의 소유 위치이고 영상 번호는 배포 묶음이다. 같은 개념·예시·핵심 설명을 반마다 따로 고쳐 서로 달라지게 만들지 않는다. 통합반의 추가 회차는 공통 단위를 나눠 설명하거나 같은 목표의 사례를 더 살펴보는 데 사용할 수 있다. 그 사례도 공통 자료에 포함해 4학년이 접근할 수 있게 한다. 한쪽에만 있는 필수 기술이나 다른 정답 기준을 만들지 않는다.

기존 실전반 8편은 비전·RUL·클라우드 등 통합반에 있던 내용이 빠져 있다. 기존 통합반도 실전반의 품질·시각화·파이프라인 설명을 같은 깊이로 포함하는지 확인해야 한다. 현재의 A·J·K만 공유하는 방식으로는 공통 내용 요구를 충족하지 않는다. M은 O·P 일부를 묶은 원고이므로 전체 내용을 대신하는 공통 원고로 취급하지 않는다.

## 실제 전환 순서와 완료 조건

1. 공통 단위별로 기존 개념·적용·판단 장면을 모아 중복과 선후 의존을 검토한다. 첫 용어 설명과 다음 장 연결을 새 순서에 맞춘다.
2. 공통 내용을 두 반의 영상 배포 묶음으로 연결한다. 영상 시수에 필요한 실제 설명과 사례를 준비하고, 제목에 4H를 적는 것으로 분량을 충족했다고 보지 않는다.
3. 같은 실습 기능을 두 반의 날짜에 맞춰 배정한다. 가이드는 해당 날의 행동과 필요한 개념을 그 자리에서 설명한다. 참조 파일 목록만으로 따라하기를 대신하지 않는다.
4. 반별 출발본은 그날 앞 단계까지의 기능을 갖춘다. 날짜가 다르므로 출발본의 상태는 다를 수 있지만, 최종 실습에서 습득하는 기능과 판단 기준은 같아야 한다.
5. 공통 필수 주제·실습 기능·핵심 사례가 양쪽 배정에 모두 있는지 대조한다. 기존 ZIP은 보존하고 실제 전환 후 새 배포 목록과 패키지를 만든다.

기존 원자료와 반별 초안은 변경 전 기록으로 보존한다. 원본 엑셀의 주제 차이는 출처로 남기되 최신 사용자 지시를 무시하는 근거로 쓰지 않는다. 이 전환은 전체 목표의 필수 작업이며 명칭 질문의 응답을 기다리는 작업이 아니다.
