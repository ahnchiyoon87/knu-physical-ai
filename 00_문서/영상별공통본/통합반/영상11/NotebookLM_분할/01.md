# 승인과 재관측의 폐루프 · 공통 이론 덱

실전반(4학년)과 통합반이 함께 사용하는 내용입니다.

제작 상태: 공통 내용 집필본. 회차별 시간 배분과 전체 흐름을 검토 중입니다. 표시한 장수는 녹화 분량의 증거가 아닙니다.

삽화는 해당 장의 대상·관계·조건을 정확히 보여 주는 독창적인 장면으로 제작합니다. 아래 지시는 실제 사진이나 실측 화면의 증거가 아닙니다. 표지나 중복 목차를 임의 추가하지 않습니다.

## U08-S050 · 도구로 얻은 제안을 승인과 재관측으로 연결합니다

**화면 문구**

도구 호출로 근거와 제안을 얻어도 상태 변경이 완료된 것은 아닙니다.

검토한 대상·내용·버전에 맞는 결정만 변경으로 연결합니다.

변경 뒤 관측한 결과가 다음 판단의 입력이 됩니다.

**삽화·구성** 조회 결과와 제안 문서에서 사람의 검토를 거쳐 소프트웨어 규칙 변경과 비교 결과로 이어지는 장면. 실제 설비 구동으로 이어지는 화살표를 넣지 않는다.

**이 장의 결론** 변경 뒤 관측한 결과가 다음 판단의 입력이 됩니다.

**다음 장 연결** 변경 뒤 관측한 결과가 다음 판단의 입력이 됩니다. 다음에는 폐루프는 실행 뒤의 결과를 다시 읽습니다로 이어갑니다.

**근거·성격** 공통 순서의 개념 연결을 위한 교육용 설계

## U08-S051 · 폐루프는 실행 뒤의 결과를 다시 읽습니다

**화면 문구**

폐루프(closed loop)는 관측·판단·행동 뒤에 새 결과를 다시 관측해 다음 판단에 반영하는 흐름입니다. 답변을 만들고 끝나는 흐름과 구별합니다.

**삽화·구성** 관측 기록·제안·승인된 설정·새 결과가 물리적인 업무 동선으로 한 바퀴 이어지는 삽화. 실제 설비 제어 신호로 오인할 연결은 없음.

**이 장의 결론** 폐루프는 실행 뒤의 결과를 다시 읽습니다.

**다음 장 연결** 우리 수업의 루프는 데이터 재생과 승인된 기록·규칙 변경을 대상으로 설계합니다

**근거·성격** 개념·근거

## U08-S052 · 우리 수업의 루프는 데이터 재생과 승인된 기록·규칙 변경을 대상으로 설계합니다

**화면 문구**

우리 수업의 루프는 데이터 재생과 승인된 기록·규칙 변경을 대상으로 설계합니다. 실제 사출기를 자율 제어하는 실증으로 확대해 말하지 않습니다.

무엇을 바꾸고 무엇을 다시 측정할지 명확히 정합니다.

**삽화·구성** 관측 기록·제안·승인된 설정·새 결과가 물리적인 업무 동선으로 한 바퀴 이어지는 삽화. 실제 설비 제어 신호로 오인할 연결은 없음. 개념 장의 그림을 복제하지 않는다. 이번에는 사례의 대상·기록·조건을 가까이 보여 주고 수치가 있으면 원문대로 별도 텍스트로 얹는다.

**이 장의 결론** 무엇을 바꾸고 무엇을 다시 측정할지 명확히 정합니다.

**다음 장 연결** 보고서를 만들고 담당자에게 보여 주면 폐루프가 완성됐나요?

**근거·성격** 근거 또는 명시된 설명용 예시

## U08-S053 · 보고서를 만들고 담당자에게 보여 주면 폐루프가 완성됐나요?

**화면 문구**

보고서를 만들고 담당자에게 보여 주면 폐루프가 완성됐나요?

그 뒤의 조치와 결과 관측이 다음 판단에 연결되는지 확인해야 합니다.

**삽화·구성** 판단 비교 삽화: 보고서를 만들고 담당자에게 보여 주면 폐루프가 완성됐나요? 관측 기록·제안·승인된 설정·새 결과가 물리적인 업무 동선으로 한 바퀴 이어지는 삽화. 실제 설비 제어 신호로 오인할 연결은 없음. 질문에서 달라진 조건을 별도 새 장면으로 표현하고 정답 문장은 그림 밖 텍스트로 둔다.

**이 장의 결론** 무엇을 바꾸고 무엇을 다시 측정할지 명확히 정합니다.

**다음 장 연결** 한 바퀴의 범위를 정했으니 어떤 행동을 맡길지 업무별로 나눠야 합니다.

**근거·성격** 교육용 판단 예시

## U08-S054 · 자율성은 업무별 권한으로 정합니다

**화면 문구**

자율성 수준은 어떤 일을 자동 수행하고 어디에서 사람의 확인을 받는지 정한 정책입니다. 수업에서 사용하는 단계 구분은 교육용 설계이며 보편 표준 번호로 소개하지 않습니다.

**삽화·구성** 조회 책상·제안 검토대·승인 서명대가 각각 다른 권한을 가진 업무 장면. 자동화 수준 숫자 대신 실제 허용 동작을 크게 표시.

**이 장의 결론** 자율성은 업무별 권한으로 정합니다.

**다음 장 연결** 조회·제안·변경의 권한을 나눕니다
