# NotebookLM에 덱 원고 넣기

전체 원고는 반별 폴더에 있다. 각 원고에는 화면에 넣을 문장과 예시, 삽화 지시, 장별 결론·연결·시간이 들어 있다. 낭독 대본은 별도로 만들지 않았다.

1. [덱 목록](README.md)에서 해당 반·영상을 고른다.
2. 전체 흐름을 검토할 때는 반별 전체 원고를 읽는다. 슬라이드를 생성할 때는 `NotebookLM_분할입력/반/영상번호`의 파일을 순서대로 사용한다. 한 파일은 최대 12장이다. 12장은 검토 편의를 위한 제작 단위이며 NotebookLM의 공식 최대 장수라는 뜻이 아니다.
3. NotebookLM의 슬라이드 생성에서 한국어와 설명이 충분한 Detailed Deck 방향을 선택하고 아래 제작 지시를 사용한다. 공식 도움말은 Detailed Deck·길이·맞춤 프롬프트 설정을 안내한다. [Google 공식 도움말](https://support.google.com/notebooklm/answer/16757456?hl=en)
4. 분할 원고의 `S번호`가 빠지거나 합쳐지지 않았는지 대조한다. 정확한 장수·배치는 생성 도구가 자동으로 보장하는 계약이 아니므로 출력물을 확인한다.
5. 번호순으로 연결한 뒤 경계의 제목·결론을 확인한다. 생성된 그림의 숫자·부품·문서 관계·영어 용어는 원고와 대조한다. PPTX 다운로드가 보이는 환경에서는 해당 기능을 사용할 수 있다. [Google의 다운로드 안내](https://support.google.com/notebooklm/answer/16757456?hl=en)

## 제작 지시

아래 지시는 **슬라이드 제작용**이며 학생에게 줄 실습 정답 프롬프트가 아니다.

```text
선택한 원고의 ‘이 분할 파일의 제작 범위’에 적힌 S번호만 순서대로 슬라이드로 만들어 주세요.
번호별 한 장을 기본으로 하되, 내용이 넘치면 글자를 줄이거나 내용을 버리지 말고 해당 번호의 하위 장으로 나누어 주세요.
이전·다음 분할과 이어지는 자료이므로 새 표지·목차·총정리 장을 임의 추가하지 마세요.

각 장의 ‘화면 문구’는 실제 화면에 남길 내용입니다. 개념·조건·예외·비교·수치의 의미를 보존해 주세요.
키워드만 남기는 요약 슬라이드도, 문장을 자막 띠처럼 붙인 슬라이드도 원하지 않습니다.
학생이 화면만 보고 지금 무엇을 설명하는지 이해할 수 있는 문단과 시각 근거를 함께 배치해 주세요.

‘삽화·구성’에 맞는 새 삽화를 제작해 주세요. 구체적인 장비·기록·업무 상황을 보여 주고 임의의 회사·사건·성능 수치를 만들지 마세요.
단순 사각형 연결이나 장식용 로봇 그림으로 대신하지 마세요. 실제 UI·터미널 캡처를 지어내지 마세요.
표·그래프의 축과 수치, 문서 관계는 정확히 유지하고 제목·라벨은 독립된 텍스트로 넣어 주세요.

‘이 장의 결론’과 다음 장 제목이 자연스럽게 이어지게 하되 제작 지시·시간표·검토 기록은 화면에 복사하지 마세요.
용어는 원고에서 처음 정의한 내용을 보존하고 이후에는 같은 용어를 써 주세요.
설명용 가정·합성·제공 자료의 보고 수치는 그 성격을 유지해 주세요.
16:9, 큰 한국어 제목, 읽기 쉬운 본문, 여백 있는 편집 디자인을 사용해 주세요.
기존 리허설의 디자인과 도형은 따라 하지 마세요.
```

## 출력물을 볼 때

- 제목과 결론이 같은 주장을 다루는가. 다음 장으로 넘어갈 이유가 보이는가.
- 용어를 설명하기 전에 그 용어로 다른 내용을 설명하지 않는가.
- 숫자·단위·분모·예외·근거 부족이 빠지지 않았는가.
- 그림이 문장보다 더 강한 인과나 실제 성능을 암시하지 않는가.
- 삽화가 단순 장식이 아니라 설명의 대상을 실제로 보여 주는가.
- 강사가 화면에 없는 내용을 오래 설명해야 하는 장이 있는가. 있으면 설명에 필요한 장을 더 만든다.

현재 산출물은 Markdown 원고다. NotebookLM 생성·PPTX 편집 가능성·렌더의 글자 잘림·삽화 정확성·녹화 길이는 아직 확인하지 않았다.
