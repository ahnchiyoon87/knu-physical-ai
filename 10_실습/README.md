# 일차별 실습 자료

새 공통 순서의 [출발본·완성본 코드](공통코드/README.md)를 생성하고 ZIP·구문·API import·Vue 소스를 검사했습니다. 기존 반별 패키지와 이름이 비슷하므로 공통코드 경로의 파일을 사용합니다. 가이드·설치 자료를 함께 담은 [수업 시작 ZIP 19개](공통배포/README.md)도 생성해 구성과 링크를 확인했습니다.


현재 두 반 공통 내용에 맞춘 [일차별 가이드](공통학생가이드/README.md)를 작성했습니다. 아래 기존 반별 출발본·완성본은 새 순서로 전환하기 전 자료입니다. 공통 가이드의 날짜와 기존 패키지 번호를 그대로 혼용하지 않습니다.


새로 작성한 가이드와 코드가 있습니다. 기존 본강 코드를 복사한 개정본이 아닙니다. 전체 강의의 최종 내용 검토는 진행 중입니다.

- [학생 가이드](학생가이드/README.md): 실전 9일·통합 10일과 합동 OT, 실행 연결 안내.
- [전체 참고 구현](완성본/equipment-assistant/README.md): 표·품질·관계·감지·모델 분석·RAG·평가·보고서·에이전트·승인.
- [일차별 공개 파일](일차별_배포/README.md): 수업 시작 ZIP과 별도 참고 완성 ZIP.
- `일차별_출발본/`: 이전 단계 코드. 첫날에는 코드 없는 뼈대가 있습니다.
- `일차별_완성본/`: 그날까지의 참고 구현. 학생 결과가 같은 모양일 필요는 없습니다.

대본은 온라인 이론에만 있으며 실습 진행 대본은 만들지 않습니다. 통합반과 4학년의 공통 내용 지시는 현재 자료의 반 명칭과 연결해 반영 중입니다.

실습은 자기 프로젝트에서 이어 갑니다. 합류할 때는 출발본을 새 폴더에서 열어 기존 작업을 보존합니다. 원시 KAMP·C-MAPSS·열화상 자료와 실제 API 키는 포함하지 않습니다. 제공 합성·교육용 문서는 출처를 구분합니다. 실제 데이터 경로는 mapping.json에서 연결합니다.

검사 범위는 코드 구문·핵심 경계·Vue 빌드·ZIP 파일 집합과 새 폴더의 API import입니다. 모델 호출·학습·GPU·DB 업무 실행·학생 완주·클라우드 배포는 하지 않았습니다. 최신 검사 대상 버전은 [현재 미결과 증거](../30_기록/전체제작_현재미결.md)를 봅니다. Drive 업로드와 ESNS 전송은 수행하지 않았습니다.
