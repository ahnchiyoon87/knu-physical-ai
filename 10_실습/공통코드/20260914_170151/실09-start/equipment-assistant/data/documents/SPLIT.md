# 모델 평가 분할

문서번호: SPLIT · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 학습과 확인

학습에 쓴 자료와 성능을 확인할 자료를 구별한다. 같은 생산 묶음이 양쪽에 섞이는지 확인한다.

## 2. 기록과 확인

결측 처리 기준과 특징 변환은 학습 자료에서 정하고 평가 자료에 적용한다. 평가 결과를 보고 기준을 바꿨다면 새 평가가 필요하다.

## 3. 적용 경계

불균형 자료는 정확도만 보지 않고 불량 누락과 정상 오판을 함께 확인한다.
