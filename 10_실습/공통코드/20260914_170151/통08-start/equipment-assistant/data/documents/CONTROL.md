# 관리 항목 연결

문서번호: CONTROL · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 무엇을 확인할지

관리 항목마다 확인 대상, 방법, 적용 기준과 기록 위치를 연결한다.

## 2. 기록과 확인

센서가 측정하는 값과 제품 품질 항목을 구분한다. 센서 기준 만족이 제품 규격 만족을 항상 뜻하지 않는다.

## 3. 적용 경계

자료가 없는 관리 항목은 자동 점검 완료로 표시하지 않는다.
