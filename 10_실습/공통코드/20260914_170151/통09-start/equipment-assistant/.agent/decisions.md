# 구조 결정

- 표·문서 벡터·업무 기록은 Postgres, 관계는 Neo4j로 나눈다. 관계의 원천은 명시한 관계표이며 두 DB 사이 반영은 대기 기록으로 드러낸다.
- 원천은 이름이 아니라 프로필과 원천 ID로 구별한다. 원본 자료가 없다고 합성 자료를 자동 사용하지 않는다.
- API와 사내 모델은 서로 다른 설정이다. 서비스 시작·설치·문법 검사에서 모델을 자동 호출하지 않는다.
- 사람 승인 권한은 서비스 조회·제안 권한과 분리한다. MCP 도구에는 승인 기능이 없다.
- 현재 구현과 검증 범위가 사실이며, 실행하지 않은 성능·완주 결과는 미검증으로 남긴다.
