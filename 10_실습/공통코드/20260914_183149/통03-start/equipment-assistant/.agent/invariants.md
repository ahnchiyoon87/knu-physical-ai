# 경계별 불변 조건

| 경계 | 입력 조건 | 출력 조건 |
|---|---|---|
| 원천 적재 | 등록 원천·필수 열·유한 수·순서 키 | 파일/매핑 해시·행 번호·LOT 파생 규칙 보존, 중복 적재 없음 |
| SQL 생성 | 선택 원천의 열 뜻과 실제 LOT 정찰 결과 | 등록 표·열만 사용하는 SELECT, 충분성 또는 부족 이유 |
| SQL 실행 | AST 검사·읽기 전용 연결 | 원문 SQL 유지, 표시 행 상한과 잘림 여부 |
| SQL 심사 | 질문·SQL·실제 결과·열 사전 | 네 항목 PASS/FAIL/UNKNOWN, 최소 수리 전후 기록 |
| 관계 적재 | 대상·종류·관계·출처 | 같은 트랜잭션에서 되읽기 대조 |
| 규칙 감지 | 동일 원천과 규칙 버전·유효 기준 구간 | 알람과 통지 억제 구별, 원인/품질 확정 없음 |
| 모델 평가 | 학습과 평가 분리·명시 라벨 의미 | 측정한 대상·범위·방법·실패 드러남 |
| 문서 검색 | 등록 문서·동일 인덱스 설정 | 해당 프로필 현행 근거, 표 머리글 보존 |
| 답변 | 근거 한 개 이상 | 주장별 유효 인용 번호 또는 거절, 의미 지지 여부 별도 |
| 도구 | 다섯 도구의 입력 계약 | none/error/failed 구별, none은 정상 판정 아님 |
| 제안 | 현재 규칙·해당 버전 이벤트·허용 범위 | 특정 제안/버전/해시의 승인 대기 |
| 결정 기록 | 저장된 사람 승인·변경되지 않은 대상 | 중복 기록 없음, 규칙/결정 원자적 갱신, 그래프 반영 대기 |
| 재개 | 동일 작업과 제안의 저장 상태 | 승인 여부 재확인, 반복과 걸음 상한 적용 |
