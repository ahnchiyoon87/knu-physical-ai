# 4M 변경 검토

문서번호: FOURM · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 사전 검토

사람·설비·재료·방법의 변경 요청에는 변경 대상, 목적, 영향 범위와 필요한 확인 항목을 적는다.

## 2. 기록과 확인

검토자와 승인자는 해당 변경안의 내용 및 버전을 확인한다. 승인된 변경안과 실행한 변경이 같은지 기록으로 연결한다.

## 3. 적용 경계

승인 후 내용이 달라지면 이전 승인을 새 변경안에 자동 적용하지 않는다. 추가 검토 필요 여부를 판단한다.
