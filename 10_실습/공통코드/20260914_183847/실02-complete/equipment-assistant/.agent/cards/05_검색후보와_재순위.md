# 필요한 문서가 없거나 뒤에 밀렸을 때

문서번호 같은 문자 단서와 표현이 다른 의미 단서는 찾는 방법이 다릅니다. 키워드와 벡터 후보를 합친 뒤 관련성을 다시 평가해 순서를 정합니다. 후보 생성과 재순위화는 별도 단계입니다.

현재 설계는 검색 후보 20과 최종 근거 5를 기본값으로 둡니다. 보편 최적값이 아니라 비교를 시작할 교육용 설정입니다. 같은 질문에서 기대 근거의 존재·순서와 답의 주장을 확인한 뒤 바꿉니다.

후보에 없는 문서는 재순위화로 생기지 않습니다. 후보를 무조건 늘리면 입력량과 혼동도 늘 수 있습니다. 현행 상태와 적용 범위는 유사도보다 먼저 확인합니다.

제공 패키지 연결: 실6의 하이브리드·리랭커 장치. 실제 모델 다운로드와 실행은 수업 환경에서 별도로 준비합니다.
