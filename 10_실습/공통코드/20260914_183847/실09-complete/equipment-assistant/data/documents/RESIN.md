# 재료 조건 확인

문서번호: RESIN · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 적용 조건

재료에 따른 권장 조건은 재료 등급과 제조사 자료의 적용 범위를 확인하여 사용한다.

## 2. 기록과 확인

다른 재료·제품에 쓰인 조건을 현재 생산의 허용 범위로 자동 채택하지 않는다.

## 3. 적용 경계

이 교육용 문서는 특정 수지의 온도·압력 수치를 제공하지 않는다. 실제 적용 수치는 원문 자료가 필요하다.
