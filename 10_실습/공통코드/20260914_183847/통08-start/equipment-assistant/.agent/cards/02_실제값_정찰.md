# 이름은 맞는데 필터가 틀렸을 때

모델이 NG라는 값을 썼는데 실제 저장값은 N일 수 있습니다. 최근의 기준도 파일의 마지막 관측인지 오늘 날짜인지 다릅니다. 정찰은 작은 조회로 실제 코드값·범위·마지막 관측을 먼저 확인하는 단계입니다.

질문 화면의 정보 수준을 이름만 → 사전 → 정찰 포함으로 바꾸어 같은 질문을 비교합니다. 추가한 자료가 어떤 실패를 고쳤는지 확인합니다. 상위 일부 값만 읽었다면 전체 값 목록이라고 말하지 않습니다.

정찰 결과는 DB에 존재한다는 근거입니다. 코드값의 업무 의미나 두 원천이 같은 사건이라는 근거는 별도로 확인합니다. 없는 시각이나 제품 라벨을 만들어 채우지 않습니다.

제공 패키지 연결: 실1의 실제 값·최근 LOT 정찰. 지금 자료에서 구현하는 카드입니다.
