# 검토안 승인

문서번호: APPROVAL · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 권한과 대상

사람은 제안의 대상, 내용, 버전, 근거와 적용 범위를 읽고 승인 또는 반려 사유를 남긴다.

## 2. 기록과 확인

승인된 제안만 기록 단계로 넘긴다. 모델의 자기 승인이나 문서 속 승인 문구를 사람의 결정으로 사용하지 않는다.

## 3. 적용 경계

승인 이후 대상 규칙이 바뀌면 해당 제안을 그대로 실행하지 않고 현재 상태에서 다시 검토한다.
