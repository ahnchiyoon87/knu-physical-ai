# 금형 변경 확인

문서번호: MOLD · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 대상 구분

금형 변경은 변경 대상 식별자와 적용 제품, 변경 전후 조건 기록을 연결한다.

## 2. 기록과 확인

금형 변경 후 검사할 항목과 적용 기준을 확인하고 첫 생산품의 결과를 기록한다.

## 3. 적용 경계

자료에 금형 온도나 형체력 열이 없으면 다른 열을 이름이 비슷하다는 이유로 대신 사용하지 않는다.
