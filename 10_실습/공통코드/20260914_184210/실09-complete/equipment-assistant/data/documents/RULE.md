# 감지 기준 변경

문서번호: RULE · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 같은 입력 비교

규칙 변경안에는 바꾸는 범위와 비교할 입력을 먼저 정한다. 이전 규칙과 새 규칙의 버전을 기록한다.

## 2. 기록과 확인

동일하게 저장한 입력을 두 규칙으로 재생하여 알람과 통지의 변화를 비교한다. 라벨이 있으면 놓친 대상도 대조한다.

## 3. 적용 경계

통지를 줄인 사실만으로 설비 문제 해결이나 품질 개선을 확정하지 않는다.
