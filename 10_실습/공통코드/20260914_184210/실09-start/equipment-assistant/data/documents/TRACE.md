# LOT와 출처 연결

문서번호: TRACE · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 범위 식별

샷·조건 기록·작업 기록은 명시된 원천과 LOT 키로 연결한다. 원천이 다르면 같은 번호여도 별개 대상이다.

## 2. 기록과 확인

파생 LOT는 생성 규칙과 원본 행 범위를 함께 보존한다. 시간 열이 없는 경우 실제 시각을 추정해 채우지 않는다.

## 3. 적용 경계

이미지 자료에 LOT 연결 근거가 없으면 센서 LOT에 자동 결합하지 않는다.
