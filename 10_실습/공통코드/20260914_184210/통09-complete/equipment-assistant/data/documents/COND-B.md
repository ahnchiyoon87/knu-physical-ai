# 조건 기록 관리

문서번호: COND-B · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 조건 대조

작업자는 시업 시 설비·제품·LOT 범위와 적용 조건표의 개정을 함께 확인한다. 각 설정값을 조건표와 대조하여 일치 여부와 변경 항목을 기록한다.

## 2. 기록과 확인

조건이 바뀐 경우 변경한 항목·전후 값·적용 대상·승인 기록을 연결하고 변경 후 첫 생산품 확인 결과를 남긴다.

## 3. 적용 경계

기록이 없으면 변경이 없었다고 추정하지 않는다. 확인하지 못한 항목은 미확인으로 구별한다.

## 4. 교육용 기록 항목표

아래 표는 수업용 기록 구조의 예시이며 실제 기업의 승인된 양식이 아니다.

| 기록 종류 | 필요한 항목 | 확인 시점 |
|---|---|---|
| 시업 조건 대조 | 설비·제품·LOT·조건표 개정 | 생산 시작 전 |
| 조건 변경 | 변경 항목·전후 값·적용 대상·승인 기록 | 변경 반영 전 |
| 변경 후 첫 생산품 | 검사 대상·검사 결과·판단자 | 변경 반영 후 첫 생산품 확인 시 |
