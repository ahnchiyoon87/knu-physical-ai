# 시업 점검

문서번호: SHIFT · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 작업 시작

작업자는 안전 점검과 설비 상태 확인을 마친 뒤 예정 제품과 설정 조건의 적용 범위를 확인한다.

## 2. 기록과 확인

점검 결과는 점검 시점·설비 식별자·항목·관측 결과·조치 필요 여부로 기록한다. 교대 인계 내용과 새 관측은 구분한다.

## 3. 적용 경계

화면에 이전 교대의 정상 기록이 남아 있어도 현재 교대의 점검 완료로 바꾸지 않는다.
