# 결과물 설명

문서번호: HANDOFF · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 다른 사람이 이어가기

설명서에는 해결하는 문제, 필요한 입력, 사용한 근거, 관찰할 결과와 적용 한계를 적는다.

## 2. 기록과 확인

다른 주제에 옮길 때 바뀌는 원천 의미, 대상 관계, 문서와 판단 기준을 구별한다.

## 3. 적용 경계

원래 주제에서 쓰던 단위를 이름만 바꿔 재사용하지 않는다. 새 자료에서 기준을 다시 확인한다.
