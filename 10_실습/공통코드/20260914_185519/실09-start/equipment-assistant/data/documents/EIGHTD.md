# 8D 기록 구분

문서번호: EIGHTD · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 검증된 결과

문제를 정의하고 임시 봉쇄, 원인 검증, 시정책 선택과 실행, 효과 확인, 재발 방지와 기여 인정을 구분한다.

## 2. 기록과 확인

AI가 제안한 원인 후보는 원인 검증 완료 칸에 자동 입력하지 않는다. 근거와 확인 상태를 함께 남긴다.

## 3. 적용 경계

해결되지 않은 문제는 미결로 유지한다. 보고서를 작성한 사실만으로 시정책의 효과를 확인했다고 하지 않는다.
