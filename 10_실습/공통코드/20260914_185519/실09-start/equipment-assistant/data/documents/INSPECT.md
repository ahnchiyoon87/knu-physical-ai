# 검사 기록 항목

문서번호: INSPECT · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 판정 근거

검사 기록에는 대상 식별자, 검사 항목, 적용 기준과 개정, 측정값, 판정, 확인 역할을 남긴다.

## 2. 기록과 확인

측정값이 없거나 기준을 확인하지 못한 항목은 합격으로 채우지 않는다. 미검사와 부적합을 분리한다.

## 3. 적용 경계

판정 기준을 바꾼 경우 이전 결과의 의미와 비교 가능 범위를 다시 확인한다.
