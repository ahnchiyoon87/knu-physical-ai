# 교육용 서비스 범위

문서번호: SCOPE · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 자동화 한계

이 서비스는 저장된 데이터를 조회하고 규칙과 모델의 결과를 검토하는 교육용 구현이다.

## 2. 기록과 확인

사람이 승인한 소프트웨어 규칙 변경 뒤 같은 입력을 재생하여 결과를 다시 관측한다.

## 3. 적용 경계

실제 설비 구동, 공정 안전 제어, 제품 출하 승인과 정비 지시를 대신하지 않는다.
