# 중단과 재개

문서번호: RESTART · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 대기 상태

중단된 작업은 작업 식별자와 저장된 제안 상태로 이어간다. 새 요청과 이전 작업을 구분한다.

## 2. 기록과 확인

재개 전에 사람의 결정이 해당 제안에 저장됐는지 확인한다. 화면에서 승인했다는 주장만으로 실행하지 않는다.

## 3. 적용 경계

기록이 이미 완료된 경우 같은 조치를 중복 기록하지 않는다. 중복 요청 여부를 결과에 표시한다.
