# 초물 확인

문서번호: FIRST · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 변경 뒤 확인

작업 시작 또는 제품·금형·공정 조건 변경 후 첫 생산품의 검사 대상과 기준을 확인한다.

## 2. 기록과 확인

검사자는 적용 규격의 개정과 측정 결과를 함께 기록한다. 부적합이 있으면 후속 생산품의 처리 범위를 별도로 판단한다.

## 3. 적용 경계

사전 승인 기록은 제품 검사 합격을 대신하지 않는다. 검사하지 못한 상태는 미검사로 남긴다.
