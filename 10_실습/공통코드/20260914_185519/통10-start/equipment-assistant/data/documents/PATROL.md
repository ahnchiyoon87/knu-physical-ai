# 자주검사 기록

문서번호: PATROL · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 작업 중 확인

작업 중 정한 확인 시점마다 현재 조건과 제품 관측을 적용 조건표에 대조한다.

## 2. 기록과 확인

설정 일치와 제품 합격은 서로 다른 항목이다. 설정이 같아도 제품 관측 결과를 생략하지 않는다.

## 3. 적용 경계

검사 횟수와 간격은 적용 작업 기준에서 확인한다. 이 교육용 문서는 특정 생산라인의 간격을 정하지 않는다.
