# 책임과 연결

입력 설정 → 데이터 적재/열 사전 → 관계표 → 규칙·모델 관측 → 문서 검색·평가 → 다섯 도구 → 상태를 잇는 에이전트 → 사람 승인 → 결정 기록/규칙 변경 → 같은 입력 재관측.

원천/기록의 정본은 Postgres, 관계 투영은 Neo4j다. 문서 벡터는 pgvector다. 모델은 공통 게이트웨이에서만 원격 호출하며 CPU 분석은 명시 분석 요청에서만 수행한다.

비컴공 사용자는 화면에서 목적·범위·기준을 결정한다. 복잡한 변환·설치·배포 명령은 코드 에이전트가 계약에 맞춰 수행하도록 문서에서 연결한다. 완성 프롬프트를 복제하는 활동으로 대체하지 않는다.

반별 일차 출발본은 해당 시점의 기능을 실제 파일로 구분한다. 최종 앱 전체를 숨겨 두고 메뉴만 가리는 방식은 사용하지 않는다. 작성 중인 사용자 코드를 덮지 않는다.
