# 분류 결과를 같은 평가 표에서 비교한다

3일차의 항상 0 기준선과 실제 특징 중요도를 참고 코드에서도 확인한다. 모델과 기준선은 동일 평가 행만 사용한다. 중요도는 학습된 숲의 불순도 감소 기반 값이며 원인·불량 확률로 표시하지 않는다. 열 ID 순서를 유지하고 길이 불일치·비유한 값·음수는 오류로 처리한다. 양성 없는 평가의 재현율은 null이다. 원천/행 관계 투영은 별도 미결이다.

API 결과 저장 및 전체 결과 조회에서 새 필드를 보존하고 화면에 비교 표를 표시한다. 기존 저장 결과에 새 필드가 없으면 기준선을 지어내지 않는다. 학습 실행 없이 순수 계산과 구조만 검사한다.
