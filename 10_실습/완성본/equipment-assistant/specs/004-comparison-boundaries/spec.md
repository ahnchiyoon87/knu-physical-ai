# 같은 행 범위와 실제 단계 상태를 비교한다

규칙 결과는 input_rows와 실제 evaluated를 구별하고 기준 구간/결측 제외 수를 표시한다. 성공 결과에서 세 수의 합이 입력 수여야 한다. 판정 가능한 행이0이면 정상으로 표현하지 않는다. PyOD는 기준 뒤 점수·예측 각각을 같은 원본 행/LOT/원천에 연결하고 길이 불일치를 오류로 처리한다. 모델 학습은 하지 않는다.

파이프라인 각 단계에서 예외나 비정상 응답이면 뒤 단계로 넘어가지 않는다. 이미 끝난 단계의 결과와 멈춘 단계를 응답에 보존하며 롤백을 했다고 주장하지 않는다. 알 수 없는 외부 예외의 원문에 인증정보가 있을 수 있어 종류만 노출한다. CSV의 not_applicable와 Neo4j의 pending/synchronized를 구별한다.
