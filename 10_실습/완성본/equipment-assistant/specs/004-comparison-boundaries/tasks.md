# 작업과 확인

- 규칙 계산 중 입력/기준/결측/판정 행 수를 직접 집계하고 유효 판정0행이면 insufficient로 중단한다. 경보0개이면 새 그래프 사건도 만들지 않았음을 구분한다.
- PyOD 점수·예측을 기준 뒤 원본 행에 결합하고 결과 표에 표시한다. 배열 길이가 다르면 오류다.
- LangGraph 네 단계의 예외/비정상 응답에서 뒤 노드를 호출하지 않고 이미 끝난 결과와 중단 위치를 반환한다. CSV not_applicable를 그래프 DB 동기화 성공으로 표시하지 않는다.
- 전체 작은 검사51개 통과(2.17초), Vite26 modules 빌드 통과. 새 비교/중단 검사9개 포함. 외부 실행은 모의 함수로 대체했으며 실제 모델·DB·Neo4j·GUI·완주 검증이 아니다.
- Starlette TestClient의 AnyIO 별칭 폐기 예정 경고1건. 검사 실패는 없으며 의존성 전체 업그레이드는 수행하지 않았다.
- 출발/완성/학생 패키지는 저장소 현재 매니페스트와 공통 검사 기록을 따른다.
