# 부적합 처리 검토

문서번호: DEVIATION · 개정: B · 상태: current

성격: 설계. 제공 패키지의 사출 현장 업무와 기록 항목을 참고해 새로 쓴 교육용 문서입니다. 실제 공장의 공식 절차서나 특정 사건의 증거가 아닙니다.

## 1. 처리 범위

부적합 관측이 있으면 해당 대상과 영향 범위를 먼저 식별한다. 처리 전 대상이 섞이지 않도록 기록한다.

## 2. 기록과 확인

재검사·보류·처리 결정은 적용 규정과 권한을 가진 역할이 판단한다. 자동 설명은 검토 자료로 제공한다.

## 3. 적용 경계

모델 점수를 승인·특채 판단으로 직접 바꾸지 않는다.
