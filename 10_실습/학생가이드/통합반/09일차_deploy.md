# 통합반 9일차 · 재시작해도 남아야 할 것을 서비스 밖에 둡니다

일정: 2027-02-03(수) 09:00~13:00 · 4시간
연결 이론: 영상9 · [이론 덱 목록](../../../00_문서/이론덱/README.md)

오늘 만들 것: **컨테이너·외부 저장소·Secret Manager 연결과 재배포 절차, 재시작 확인 기준**

## 0:00–0:20 · 오늘 작업을 엽니다

컨테이너는 실행에 필요한 파일과 환경을 묶은 단위입니다. Cloud Run의 컨테이너 로컬 파일은 영구 저장소가 아닙니다. 오늘의 핵심 판단은 표·벡터·그래프·평가 기록 중 무엇이 재시작 뒤에도 남아야 하는지 정하는 것입니다. 승인 기능은 다음 일차에 추가합니다.

ESNS에서 오늘 공개된 Drive 링크의 **통09-start**와 이 가이드를 받습니다. 잘 이어지는 자기 프로젝트가 있으면 그것을 씁니다. 출발본은 이전 단계의 코드이므로 오늘 기능은 직접 요청해 만듭니다. 내 작업이 막혔다면 기존 폴더는 보존하고 출발본을 새 폴더에 풉니다. 두 폴더에 같은 서버를 동시에 띄우지 않습니다.

VS Code에서 오늘 작업 폴더를 열고 README의 실행 순서를 확인합니다. 이미 만든 서비스는 연결 확인에서 서버·DB 상태를 읽고, 오늘 필요한 원천 파일과 모델 준비 여부를 따로 확인합니다. 첫날 코드 없는 뼈대에서는 아직 앱 화면이 없는 것이 맞습니다. 설치가 남았다면 아래 네 문서 중 해당 단계만 마칩니다.

- [Google Cloud 세팅](../../../실습가이드핸즈온문서/1_GoogleCloud세팅.pdf)
- [VS Code와 코딩 에이전트](../../../실습가이드핸즈온문서/2_VSCode설치및_코딩에이전트세팅.pdf)
- [Docker 설치](../../../실습가이드핸즈온문서/3_도커설치및세팅.pdf)
- [실습 의존성 설치](../../../실습가이드핸즈온문서/4_실습의존성설치.pdf)

설치 뒤의 서버·자료 연결은 [실행 연결 안내](../실행_연결_안내.md)에 모았습니다. 이 문서는 설치 프로그램 설명을 반복하지 않고 실제 프로젝트의 실행과 오류 위치를 이어 줍니다.

자료를 선택할 때 synthetic은 교육용 합성, kamp는 직접 연결한 KAMP 원본입니다. 원본을 선택했는데 파일이 없으면 원본 경로를 먼저 준비합니다. 합성을 썼다면 결과에도 합성이라고 표시합니다. 특정 LOT의 실제 숫자가 가이드와 같아야 통과하는 수업은 아닙니다.

## 0:20–1:10 · 저장 위치와 비밀의 위치를 먼저 나눕니다

Cloud Run은 서비스를 실행하고, 외부 Postgres는 표·벡터·기록을 보존하며, 외부 Neo4j는 관계를 보존합니다. Secret Manager는 접속 비밀을 코드 대신 보관합니다. 로컬 DB 주소 localhost는 다른 서버의 내 노트북을 뜻하지 않습니다.

**지금 해 볼 일**

배포.md의 준비표에서 외부 DB·그래프·런타임 계정·비밀 이름을 정합니다. 데이터 파일과 문서 원본의 보관 위치도 정합니다. 이미지에 .env·키·학생 원본이 들어가지 않게 .dockerignore와 Dockerfile의 COPY 범위를 확인합니다.

에이전트에게 줄 요청은 자신의 말로 씁니다. 원하는 행동과 무엇을 보면 됐다고 할지를 전달하고, 나온 이해가 다르면 바로잡습니다. 구현 문법을 직접 완성할 필요는 없습니다.

**됐는지 확인합니다**

DB URL과 그래프 주소가 외부 저장소를 가리키고 비밀값은 코드에 없습니다. 검색 모델 파일을 이미지에 준비했는지 여부가 분명해야 합니다.

**막혔을 때**

무료 계정이라는 이유로 용량·휴면·접속 제한을 가정하지 않습니다. 실제 계정 조건을 확인하고 실행 범위와 비용을 선택합니다.

준비한 환경에서 같은 이미지를 올립니다.

## 1:10–2:00 · 주소에서 읽고 재시작 뒤 다시 읽습니다

헬스체크 200은 정해 둔 연결 확인이 통과했다는 뜻입니다. 표 질문·검색·그래프가 모두 올바르다는 증거는 아닙니다. 저장소별 확인 대상이 필요합니다.

**지금 해 볼 일**

선택한 계정에서 배포 스크립트를 실행하고 IAM 인증된 주소로 접속합니다. /health 뒤에 기존 표 한 집계·현행 문서 한 검색·관계 경로를 확인합니다. 새 리비전을 올린 뒤 같은 저장 대상이 남는지 다시 읽습니다. 오늘 출발본에는 아직 없는 승인 대기를 확인했다고 쓰지 않습니다.

에이전트에게 줄 요청은 자신의 말로 씁니다. 원하는 행동과 무엇을 보면 됐다고 할지를 전달하고, 나온 이해가 다르면 바로잡습니다. 구현 문법을 직접 완성할 필요는 없습니다.

**됐는지 확인합니다**

표·문서 인덱스·그래프·평가 기록의 존재가 재시작 전후 같은지 봅니다. 로컬 trace 파일은 현재 인스턴스 범위이고 Cloud Logging이 재시작을 건너는 기록임을 구분합니다.

**막혔을 때**

DB가 연결돼도 reader 계정이나 스키마가 빠졌을 수 있습니다. 외부 DB에 bootstrap을 적용했는지 확인하고 브라우저에 관리자 키를 넣지 않습니다.

손으로 반복한 배포를 같은 입력의 한 명령으로 묶습니다.

## 2:00–2:50 · 재배포 명령의 입력을 고정합니다

배포 재현성은 같은 코드뿐 아니라 이미지 버전·설정·비밀 버전·DB 스키마가 함께 맞는 것입니다. latest라는 이름만으로 같은 입력이라고 보장되지 않습니다.

**지금 해 볼 일**

deploy.ps1 또는 deploy.sh에 사용할 프로젝트·리전·서비스·이미지 버전·비밀 연결 이름을 정합니다. 비밀값 자체는 명령 인자로 적지 않습니다. 두 번 배포했을 때 별도 DB가 새로 생기지 않고 기존 상태를 읽는지 확인합니다.

에이전트에게 줄 요청은 자신의 말로 씁니다. 원하는 행동과 무엇을 보면 됐다고 할지를 전달하고, 나온 이해가 다르면 바로잡습니다. 구현 문법을 직접 완성할 필요는 없습니다.

**됐는지 확인합니다**

어떤 이미지와 비밀 버전을 썼는지 다시 찾을 수 있어야 합니다. 스크립트 파일이 있다는 사실과 배포 성공을 구분합니다.

**막혔을 때**

배포 권한 오류는 앱 버그가 아닐 수 있습니다. 빌드 계정과 실행 계정의 역할을 나눠 첫 실패 메시지부터 확인합니다.

다른 사용자가 처음 보는 서비스에서도 같은 목적을 이해할 수 있는지 봅니다.

## 2:50–3:40 · 다른 사람이 짧은 동선을 따라오게 합니다

사용자에게 필요한 것은 내부 스택 목록보다 무엇을 넣고 어떤 근거를 읽을지입니다. 공유할 계정 접근과 서비스 토큰의 역할도 나눕니다.

**지금 해 볼 일**

수업에서 허용된 접근 방식으로 옆 학생에게 서비스의 작은 동선 하나를 설명합니다. 실제 공유는 본인이 진행합니다. 다른 화면이어도 자료 선택·결과·근거·상태가 읽히는지 확인합니다. 다음 일차 승인 기능을 추가하면 같은 배포 경로로 갱신할 준비를 합니다.

에이전트에게 줄 요청은 자신의 말로 씁니다. 원하는 행동과 무엇을 보면 됐다고 할지를 전달하고, 나온 이해가 다르면 바로잡습니다. 구현 문법을 직접 완성할 필요는 없습니다.

**됐는지 확인합니다**

처음 보는 사람이 기능의 범위와 부족한 조건을 알 수 있어야 합니다. 공개하지 않은 서비스는 공개 완료라고 보고하지 않습니다.

**막혔을 때**

접근이 막히면 무조건 전체 공개로 바꾸지 않고 수업의 IAM 접근 방식을 확인합니다. 화면의 서비스 토큰은 Cloud Run IAM 권한을 대신하지 않습니다.

다음에는 이 주소에서 사람의 결정까지 받아 한 바퀴를 닫습니다.

## 3:40–4:00 · 오늘 결과를 설명합니다

직접 실행한 한 동선을 골라 입력→처리→결과→근거를 짧게 설명합니다. 원하는 기능을 어떻게 요청했는지, 결과를 무엇으로 확인했는지, 다음 기능과 어떻게 연결했는지, 어디까지 말할 수 있는지가 보이면 됩니다. 다른 학생과 화면이나 답 문장이 같을 필요는 없습니다.

오늘 작업을 저장합니다. 다음에 열 경로와 마지막으로 되는 동작을 README에 남기면 이어가기 쉽습니다. 개인 비교 노트나 추가 제출 형식을 따로 요구하지 않습니다. 완성본은 본인 작업과 비교할 때 사용하고, 다음 일차에는 다음 출발본으로 다시 합류할 수 있습니다.

모델 호출·학습·배포를 실제로 하지 않은 항목은 미실행으로 표시합니다. 문법 검사나 화면 빌드가 됐다는 이유로 실습 전체를 완료했다고 적지 않습니다.
