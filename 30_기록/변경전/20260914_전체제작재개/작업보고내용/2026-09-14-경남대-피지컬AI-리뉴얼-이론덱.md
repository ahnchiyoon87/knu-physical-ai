# 경남대 피지컬 AI 리뉴얼 이론 덱 작성 결과

2026-09-14. 실제 일정에 연결한 상세 이론 덱 Markdown 19편을 작성했고 문서 정합성 120항목을 확인했다. 오늘의 덱 원고 제작 범위가 완료되었으며 강의 전체 구현 완료는 아니다.

기존 본강은 일정 확정 전에 만들어진 자료였다. 리뉴얼 ZIP의 확정 방향과 엑셀을 기준으로 새로 구성하여, 강사가 NotebookLM에 넣기 전에 반별 흐름과 각 장의 설명을 검토할 수 있도록 했다.

| 요구 | 변경 전 | 변경 후 | 확인 근거 |
|---|---|---|---|
| 새 일정의 상세 이론 | 리뉴얼 패키지의 일정·설계·참고자료 | 실전반 8편·통합반 11편, 영상별 실습일 연결 | 일정 추출값과 19편 메타데이터 대조 |
| 화면 중심의 설명 흐름 | 제작 방향과 리허설 참고 PPTX | 1,170장에 화면 문장·삽화 지시·결론·다음 장 연결 | 덱 매니페스트와 실제 Markdown |
| NotebookLM 입력 | 완성된 반별 덱 원고 없음 | 전체 원고와 일치하는 분할입력 100개 | 분할 장 번호와 본문 일치 검사 |
| 다음 실습 제작 연결 | ZIP 설계와 설치 PDF | 일차별 출발 상태·도달 결과·가이드 원칙 명시 | 현재 커리큘럼·제작 기준·인계 |
| 생성물 검토 부담 | 상세 원고 검토 전 단계 | 편별 60~69장으로 검토량 증가; 최대 12장씩 대조하도록 분할 | 덱 목록과 분할 파일 수 |

장별 구성의 실제 예: 실전반 평가 영상은 “검색 정밀도는 찾은 후보의 적합성을 봅니다” → 후보 다섯 개 중 둘이 필요한 사례 → “필요한 조항 하나만 찾아 정밀도가 높습니다. 검색이 충분한가요?” → 검색 재현율로 이어진다. 정의·예시·한계가 다음 개념을 부르는 형태다.

| 확인 | 기대 | 실제 | 판정 |
|---|---|---|---|
| 일정·번호·필수 항목·분할·참조·산술 | 원자료 및 작성 계획과 일치 | 120항목 통과, 실패 0 | 문서 범위 확인 |
| 영상 시간 배분 | 편별 240분 | 19편 모두 합계 일치 | 계획 확인, 발화 실측 아님 |
| 입력 원본 보호 | 원본 변경 없음 | ZIP·HTML·PDF 4개·참고 PPTX 해시 7개 일치 | 확인 |
| 실습·모델 실행 | 간단 확인만, 비싼 모델 사용 금지 | 실습 완주·유료 모델·GPU 호출 미수행 | 사용자 범위 준수 |

PPTX·삽화·낭독 대본과 실습코드·출발본·실행 가이드는 후속이다. 실제 영상 길이와 화면 가독성은 NotebookLM 생성물 대조 및 낭독으로 확인해야 한다. 설치 PDF 내용과 원시 데이터 전체도 이번에 재검증하지 않았다.
