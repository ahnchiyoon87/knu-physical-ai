# 규칙과 시계열 변화 · 공통 이론 덱

실전반(4학년)과 통합반이 함께 사용하는 내용입니다.

제작 상태: 공통 내용 집필본. 회차별 시간 배분과 전체 흐름을 검토 중입니다. 표시한 장수는 녹화 분량의 증거가 아닙니다.

삽화는 해당 장의 대상·관계·조건을 정확히 보여 주는 독창적인 장면으로 제작합니다. 아래 지시는 실제 사진이나 실측 화면의 증거가 아닙니다. 표지나 중복 목차를 임의 추가하지 않습니다.

## U03-S097 · 시험 구간을 보고 창 길이를 골랐습니다

**화면 문구**

여러 창 길이를 시험에 대어 가장 잘 맞는 것을 최종 성능으로 보고했습니다.

평가 구조를 어떻게 바로잡을까요?

**삽화·구성** 교육용 사례의 구체적 업무 삽화: 여러 창 길이를 시험에 대어 가장 잘 맞는 것을 최종 성능으로 보고했습니다. 비교에 필요한 기록과 조건만 넣는다. 회사명·인물명·실제 성능을 만들지 않는다.

**이 장의 결론** 평가 구조를 어떻게 바로잡을까요?

## U03-S098 · 창 길이는 검증 구간에서 선택하고 새 시험에서 확인합니다

**화면 문구**

창 길이는 검증 구간에서 선택하고 새 시험에서 확인합니다. 이미 본 시험만 있다면 선택 편향의 한계를 밝혀야 합니다.

다른 선택을 했다면, 그 선택이 성립하려면 어떤 추가 조건이 필요한지 확인합니다.

**삽화·구성** 이전 문제 장을 복제하지 않고 판단의 결정적 근거를 확대한다. 창 길이는 검증 구간에서 선택하고 새 시험에서 확인합니다. 이미 본 시험만 있다면 선택 편향의 한계를 밝혀야 합니다. 문장은 독립된 큰 텍스트로, 삽화는 근거의 위치를 설명한다.

**이 장의 결론** 창 길이는 검증 구간에서 선택하고 새 시험에서 확인합니다

**다음 장 연결** 창 길이는 검증 구간에서 선택하고 새 시험에서 확인합니다 다음에는 확인한 결과를 다음 판단에 넘깁니다로 이어갑니다.

## U03-S099 · 확인한 결과를 다음 판단에 넘깁니다

**화면 문구**

생산 조건에 맞는 규칙과 시간 구간을 사용해 변화를 찾습니다.

변화를 찾는 기준을 배웠습니다. 다음에는 이미지와 수명처럼 입력과 목표가 다른 문제를 구별합니다.

**삽화·구성** 앞 장면에서 확인한 기록과 다음 작업에 넘길 근거를 구체적인 문서와 화면으로 연결한다. 확인되지 않은 칸은 임의로 채우지 않는다.

**이 장의 결론** 변화를 찾는 기준을 배웠습니다. 다음에는 이미지와 수명처럼 입력과 목표가 다른 문제를 구별합니다.

**다음 장 연결** 변화를 찾는 기준을 배웠습니다. 다음에는 이미지와 수명처럼 입력과 목표가 다른 문제를 구별합니다.
