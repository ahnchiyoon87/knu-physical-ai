# 전체 제작 현재 미결

이 문서는 제작 중 재개 기록이며 최종 보고가 아니다. 원래 goal은 active다.

## 최신 지시

통합반과 4학년은 같은 내용, 대본은 온라인 이론만. 4학년의 현재 원자료 반 명칭을 비동기로 확인 중이다. 해당 답변을 먼저 반영한다. 실습 대본은 생성하지 않았다.

## 지금까지 작성한 범위

- 이론 덱 19·1,170장, NotebookLM 입력 100개. 기존 작성본을 보존했다.
- 온라인 대본 19·1,170장. `narration_core.py`, `narration_models.py`, `narration_rag.py`, `narration_operations.py`가 독립 개념 발화 소스다. 실전 영상8의 공유 개념은 O/P 원고와 연결한다.
- 19일차 가이드와 OT·실행 연결, RAG 질문 20·빈 작성틀 30·강사 기대 근거 20.
- 신규 전체 앱, 출발본 19, 일차 완성본 19, 수업 시작 ZIP 19. 시작 ZIP에 오늘의 완성 코드를 넣지 않는다. 이전 ZIP도 삭제·덮기 없이 보존한다.
- 품질: 원본 보존 정제 뷰, 오류 코드 NULL 처리, 범위 표시, 지정 열 쌍 비교, 근거 있는 뜻 초안. analysis_view=clean을 명시하면 질문·곡선·감지가 정제 뷰를 읽는다.
- 규칙: LOT 조건표 기준 ±폭, 앞 200행 평균 대비 %, 쿠션 상승 AND 계량시간 하락. 결측·기준 평균 0·중복 조건표·조건 누락은 부족 상태. 표준편차 방식도 별도 명시 시 사용할 수 있다.
- 예측: 선택한 LOT의 마지막 구간을 입력에서 남기는 홀드아웃, 직전값 기준선·MAE·포함률, 예측 그래프. 이 결과는 코드를 작성했으며 실제 Chronos 호출은 하지 않았다.
- 파이프라인: 적재→감지→선택한 예측→그래프 반영. 예측 미선택과 실패를 구분한다.
- 에이전트: 이벤트→관계→문서→조건 변경·초물검사·4M 초안→사람 승인→소프트웨어 규칙 기록·재생. 자율성 0=조회, 1=초안, 2=승인 연결. 실제 검사·신고·설비 조작을 했다고 표시하지 않는다. 초안 묶음 재조회와 8D 검토 응답이 있다.
- 비전: 명시한 이미지 지표, CPU 모델 경로, 원본/히트맵·임계값 비교 화면. Anomalib 2.6.2 공식 wheel API를 대조했으며 학습 실행은 하지 않았다.

## 계속 처리할 일

최신 집필 진전: J(RAG)·K(평가)의 적용 장면 18개씩과 개별 사례 6개씩을 주제별 발화로 바꿨다. 두 반 연결 4개 영상에 적용해 대본 96개 구간과 화면 72장을 수정했다. `narration_application.py`·`narration_case_review.py`가 소스다. `적용대본_대조검사.json`은 전체·분할·대본 일치와 나머지 15개 덱 보존을 확인한다. 일반화된 적용·사례 문장을 모두 고쳤다는 뜻은 아니다. 다음 집필은 O/P 에이전트·폐루프의 해당 구간이다.

1. **대본 품질·분량**: 19편은 생겼지만 나머지 적용·판단 구간의 반복 문장을 주제별 해설로 바꾸고 화면 밖 추가 설명을 대조해야 한다. J/K의 불필요한 반복을 없앤 뒤 해당 편은 약 1.5만~1.6만 자다. 다른 편은 약 1.6만~2.2만 자다. 계획 4H에 맞는 낭독 분량이라고 판정하지 않는다. 단순히 240분을 적거나 일시정지 시간을 더해 충족했다고 하지 않는다.
2. **전체 의미 검토**: 기존 덱 1,170장을 전체 요구와 대조하는 검토가 아직 끝나지 않았다. 파일 수·해시·제목 연결 검사는 의미 검토를 대신하지 않는다. 규칙의 %/표준편차와 이전 가이드 문구 같은 차이를 계속 찾아 맞춘다.
3. **학생 자료의 밀도**: 현재 가이드 4천~5천 자대다. 코드 입력과 핵심 요청을 짧게 설명했지만 실제 자기 제작 동선의 빠진 설명, 장치 카드와 강사 비교 안내를 보완해야 한다. 개인 노트나 통제 의무를 추가하지 않는다.
4. **코드 미결**: 실제 DB·모델은 사용자 지시로 실행 제외. 코드 수준에서 이벤트 선택 범위·긴 모델 입력·판정 상태, RAG/그래프 연결, 문서 양식과 승인 정책, 증분 파일의 새 원천 설정을 검토한다. 서비스의 일반 대화와 초안 일부 재조회는 서로 다른 기능이며 자연어 후속 대화를 완성했다고 과장하지 않는다.
5. **배포**: Docker는 RAG/evaluation 경로 중심이며 CPU 모델 전체 클라우드 학습을 실행한 구조로 말하지 않는다. agent가 포함된 최종 통합 완성본의 MCP 복사를 보존하도록 고쳤고 출발·완성 ZIP 38개를 다시 추출해 검사했다. 이후 코드 변경이 생기면 해당 매니페스트와 다시 대조한다. 시작 ZIP 19개의 가이드·자료 공개 범위는 최종 의미 검토가 필요하다.
6. **생성 소스 보호**: build_lab_data.py/build_lab_documents.py/build_transfer_data.py는 mapping의 joins·quality_rules·clean_table과 COND-B §4를 덮을 수 있다. 직접 추가한 내용을 생성 소스에 반영하거나 재생성 전에 보존해야 한다. build_agent_relations.py는 교육용 절차 관계를 추가하며 앞 단계 출발본에서는 문서 관계를 제외한다.
7. **검사**: 모든 상대 링크와 명령 옵션, ZIP 구성, 출발/완성 기능 경계를 대조한다. 정제 분석·비전·예측·세 초안 같은 최근 변경의 정적 연결을 확인한다. 화면 육안 확인은 CUA 브라우저가 없어 미검증이다.
8. **현재 문서와 최종 보고**: 작업계획·요구반영표·APP spec/tasks·기존 보고서에 현재 범위와 미검증을 맞춘다. 전체가 끝나기 전에 완료를 선언하지 않는다.

## 검사 증거

- 작은 경계 검사 30 passed, 2.26초, Starlette anyio alias 경고 1개. 외부 모델·DB 없이 실행했다.
- 최신 전체 frontend: Vite 25 modules, 성공.
- `패키지_구조검사.json`: 직전 38 ZIP 실제 추출, 파일 집합/해시/구문/API import 오류 0. 검사기는 정상·깨진 구문 모두 확인했다.
- `Vue_구문검사.json`: 최신 예측 그래프를 포함해 345 SFC, 오류 0.
- `현재문서_링크검사.json`: 문서 169개, 로컬 링크 378개, 누락 0. 정상·누락 링크의 검사기 확인도 수행했다.
- `적용대본_대조검사.json`: J/K의 화면 72장·대본 96개 구간 반영 및 나머지 15개 덱의 해시 보존. 시간 분량이나 전체 강의 의미 검토 완료의 증거는 아니다.
- CUA `getBrowser`는 `No browser is available`. 기본 UI 검토 서버 시작만 확인하고 종료했다. 실제 화면 검수/캡처 없음.
- 유료 모델, GPU, 가중치 다운로드, DB 업무, 학생 실습 완주, 클라우드 배포, 외부 업로드·전송은 미실행.

원본 KAMP·열화상·C-MAPSS 보유 경로와 반 명칭 질문은 사용자 응답을 기다린다. 나머지 집필·코드·구성 작업은 계속한다.


## 제작 원천 보완 · 2026-09-14

품질 규칙·정제 뷰·중복 열 후보·표 조인, COND-B 기록 항목표와 절차 관계를 생성 도구에 반영했다. 절차 관계 도구는 import 시 쓰지 않고 main(app)으로 대상 폴더를 받는다. 임시 폴더에서 네 도구를 실행해 44개 생성 자산의 내용이 현재 자료와 일치함을 확인했다. ## 에이전트·폐루프 적용 원고 보완 · 2026-09-14
