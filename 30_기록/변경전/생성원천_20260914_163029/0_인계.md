# 경남대 피지컬 AI 리뉴얼 · 현재 상태

원래 전체 goal은 active다. 덱만으로 완료 판정했던 오류를 정정하고 이론 덱·온라인 이론 대본·실습가이드·코드·일차별 합류 자료를 제작하고 있다. 파일 생성과 전체 완료를 구별한다.

## 최신 사용자 지시

“통합반과 4학년은 내용똑같, 이론만 온라인 이론만 대본이 필요한거알지?”

- 대본은 온라인 이론만 작성한다. 실습·설치·현장 진행 대본을 추가하지 않는다.
- 통합반과 4학년은 같은 내용을 사용한다. 원자료에는 실전반·통합반만 있어 ‘4학년=실전반’인지 ‘통합반에 포함된 대상’인지 명칭을 비동기로 확인 중이다. 답이 오면 그 뜻을 우선하고 일정·공통 원고 연결을 맞춘다. 확인 없이 두 반의 시수·주제를 임의로 합치지 않는다.

## 실제 산출물

1. [이론 덱](이론덱/README.md): 기존 일정 기준 19편·1,170장·NotebookLM 분할 100개. 전 장 의미 검토와 최신 공통 내용 지시의 연결은 남아 있다.
2. [온라인 이론 대본](대본/README.md): 19편·1,170장 발화 집필본. 개념 대본은 별도 작성했다. J/K(RAG·평가)는 적용·개별 사례 96개 구간을 다시 집필하고 화면 72장에 핵심 구분을 추가했다. 나머지 적용·판단 반복 틀은 보완이 필요하다. 편별 약 1.5만~2.2만 자이며 4H 녹화 분량 충족으로 판정하지 않는다.
3. [학생 가이드](../10_실습/학생가이드/README.md): 19일차와 OT·실행 연결 안내. 행동 옆에 설명·확인·회복을 둔다. 최신 코드와 전체 의미 대조 중이다.
4. [실습 코드](../10_실습/완성본/equipment-assistant/README.md): 신규 Vue/FastAPI/Supabase·pgvector/Neo4j/MCP/LangGraph 서비스. 규칙·CPU 모델·RAG·평가·세 초안·승인·8D 연결 코드가 있다.
5. [배포 파일](../10_실습/일차별_배포/README.md): 출발본 19, 일차 참고 완성본 19, 수업 시작 ZIP 19. 현재 APP의 마지막 변경 이후 재생성과 검사가 필요할 수 있으므로 매니페스트와 검사 시점을 대조한다.

## 현재 증거와 한계

- 작은 경계 검사 30개 통과, 2.26초. 모델·DB·학생 완주가 아니다. Starlette anyio alias 경고 1개.
- 최신 전체 프런트엔드 Vite 빌드 25 modules 성공.
- 예측 평가·그래프·가이드 변경 뒤 ZIP 38개를 새 임시 폴더에 풀어 집합·해시·Python 구문·API import를 다시 확인했다. Vue 345개 구문·로컬 import 오류 0, 현재 문서 로컬 링크 378개 누락 0이다. J/K 집필 변경은 전체·분할·대본에 일치하며 다른 15개 덱은 보존됐다.
- 기본 서버는 시작됐지만 CUA가 `No browser is available`을 반환해 화면 육안 확인은 못 했다. 검사 서버는 종료했다. 가짜 캡처를 만들지 않는다.
- 실제 원시 데이터 위치 질문은 응답 대기다. 합성 자료를 원본인 것처럼 대체하지 않는다.
- 모델 이름·키·가격·사내 모델 가용성은 임의로 확정하지 않는다. 유료 호출·가중치 다운로드·학습·DB 업무 실행·배포·ESNS 전송은 하지 않았다.

## 이어서 할 일

[현재 미결](../30_기록/전체제작_현재미결.md)이 상세 작업 목록이다. 완료 파일을 처음부터 다시 만들지 않는다. 대본의 반복·시간 분량과 화면 대조, 원문 요구 대비 실습 연결, 반 명칭 응답 반영, 최신 패키지 재생성, 링크·의미 검토, 현재 요구반영표와 기존 통합 보고서 갱신을 이어 간다.

제작 소스는 `20_도구`에 있다. build_decks.py에 전체·분할 원고의 편집 보호 검사를 추가했다. 적용 구간만 수정할 때는 `revise_deck_sections.py J K`처럼 지정 키의 적용 장면만 바꾸며, 현재 파일 검증·변경 전 보존·구간 밖 변경 차단을 수행한다. 대본·가이드·출발본·완성본 제작기도 관리 파일의 사용자 편집을 발견하면 중단한다. 원자료 ZIP·HTML·설치 PDF와 기존 강의 자료는 보존한다. 현재 원고를 덮는 재생성을 습관적으로 하지 않는다.
