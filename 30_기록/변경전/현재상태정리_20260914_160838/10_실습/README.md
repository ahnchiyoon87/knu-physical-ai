# 실습 제작의 현재 상태

이 폴더는 기존 본강의 프로젝트 구조에 맞춘 새 실습 위치다. **현재 신규 실습코드·완성본·출발본·일차별 실행 가이드는 제작되지 않았다.** 오늘은 이론 덱을 우선 작성했다.

실습은 [리뉴얼 제작 기준](../00_문서/1_규범.md)과 [현재 커리큘럼](../00_문서/2_커리큘럼.md)에 맞춰 새로 만든다. 설치 PDF 4개는 프로젝트 루트의 `실습가이드핸즈온문서`에 보존되어 있다. 실제 실행 가이드는 설치 문서 뒤에 별도로 작성하며, 각 행동 옆에서 이유와 배경을 짧게 설명한다.

후속 산출물의 역할:

- `완성본/`: 강사가 비교·참고할 완성 구현. 실제로 확인한 범위만 동작 상태로 기록한다.
- `출발본/`: 해당 일차 시작에 필요한 이전 단계의 완성 상태. 학생이 자기 작업을 보존하고 합류할 수 있게 한다.
- `가이드/`: 일차별 입력·행동·관찰·판단을 위에서 아래로 읽는 문서. 완성 프롬프트를 복제시키는 방식으로 만들지 않는다.
- `배포/`: 해당 일차에 제공할 코드와 가이드. 실제 Google Drive 링크는 준비 후 연결한다.

위 하위 폴더 이름은 후속 제작 배치다. 파일이 이미 있거나 배포 가능하다는 뜻이 아니다. 개인 노트 제출·부정행위 방지·미시청자 제한 기능은 만들지 않는다.
