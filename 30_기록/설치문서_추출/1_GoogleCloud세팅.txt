Google Cloud 세팅
무료 크레딧 $300 받고, 내 PC를 Google Cloud에 연결한다.
끝나면 프로젝트 ID 하나가 남고, 2번 문서에서 그 값을 쓴다.
Google Cloud에 가입해 무료 크레딧을 받고, PC에 Google Cloud SDK를 설치해 내 계정으
로 로그인해 둔다. 이렇게 해 두면 VS Code(2번 문서)가 이 출입증을 읽어 Gemini 모델을 쓰
고, 사용한 만큼 크레딧에서 빠진다. 결제 카드는 확인용으로 등록할 뿐 실제 청구는 없다.

2장. 프로젝트 ID 확인 — 이 문서에서 가장 중요한 값
7
프로젝트 ID 복사해 두기
console.cloud.google.com 첫 화면의 「무료 체험판 사용 중」 상자 오른쪽에 ID: … 줄이 있다.
그 옆 복사 아이콘을 누르거나 값을 드래그해서 메모장에 붙여 둔다.
그림 2-1. 콘솔 첫 화면 — 「ID:」 줄이 프로젝트 ID (빨간 네모). 이 문서와 2번 문서에서 그대로 쓴다
확인 · 메모장에 프로젝트 ID 가 적혀 있다. 이 값은 이 문서 4장과 2번 문서 5장에서 그대로 쓴다.
주의 · 프로젝트 이름(My First Project)과 프로젝트 ID(my-project-xxxxxx 처럼 영문·숫자·하이픈)는 다르다.
필요한 건 ID다.
화면이 다를 때 · 첫 화면에 그 상자가 안 보이면 → 맨 위 My First Project ▾ 를 누르면 뜨는 「프로젝트 선
택」 창의 ID 열에서 같은 값을 볼 수 있다.

3장. Google Cloud SDK 설치 — 거의 자동으로 진행된다
PC에 gcloud라는 명령 도구를 설치한다. 설치 파일을 실행하면 필요한 것(파이썬 포함)을 알아서 내려받고, 끝나면 검은
창과 브라우저가 저절로 열려 로그인까지 이어진다. 당황하지 말고 아래 순서대로 따라가면 된다.
8
설치 파일 내려받아 실행
브라우저에서 cloud.google.com/sdk/docs/install 로 간다.
Windows 항목의 GoogleCloudSDKInstaller.exe 링크를 눌러 내려받고 실행한다.
마법사는 전부 기본값 그대로 다음 → 다음. 「Install Bundled Python」 체크는 그대로 둔다.
마지막 화면의 체크박스(「Start Google Cloud SDK Shell」「Run gcloud init」)도 그대로 둔 채 마침.
화면 참고
화면 순서: Welcome → 라이선스 동의 → 설치 위치 → 구성요소 선택(Install Bundled Python · Beta
Commands 체크박스) → 설치 진행 → 마지막 화면(바로가기 만들기 · Start Google Cloud SDK Shell · Run
gcloud init 체크박스). 전부 기본값.
cloud.google.com/sdk/docs/install-sdk (공식 설치 안내, 2026-09 기준)
brunch.co.kr/@smalljiny/9 (한국어 마법사 캡처)
youtube.com/watch?v=DTc16BpsSbc (Windows 11 설치 영상, 2026)
그림 3-1 · 3-2. 설치 마법사 — 구성요소 선택(Install Bundled Python 체크 유지) → 마지막 화면(체크박스 그대로 두고 마침)
확인 · 마침을 누르면 검은 창이 저절로 열리고 글자가 올라간다. 다음 단계로.
화면이 다를 때 · 설치 도중 「VCRUNTIME140.dll」 또는 「Visual C++ … Redistributable」 이 들어간
오류 창이 뜨면 → 브라우저에서 aka.ms/vs/17/release/vc_redist.x64.exe 를 받아 설치하고 PC를 다시 시
작한 뒤 이 단계를 처음부터 다시 한다. 파이썬이 필요로 하는 윈도우 부품이 빠진 PC에서만 나오는 드문 경우
다.

4장. 마무리 두 줄 — 출입증 저장과 Vertex AI 켜기
3장의 로그인은 gcloud 명령 도구용이다. VS Code가 읽는 출입증(ADC)은 따로 한 줄 더 저장해야 하고, Gemini 모델을
쓰려면 Vertex AI 스위치를 켜야 한다. 같은 검은 창에서 두 줄만 붙여넣는다.
10
출입증 저장 — gcloud auth application-default login
아래 한 줄을 붙여넣고 Enter .
gcloud auth application-default login
브라우저가 다시 열린다. 같은 계정을 고르고 허용. 「인증되었습니다」 페이지가 뜨면 닫는다.
그림 4-1. 결과 — Credentials saved to file … 과 Quota project "…" (빨간 네모가 프로젝트 ID)
확인 · 검은 창에 Credentials saved to file: […application_default_credentials.json] 이 보인다. 그
아래 Quota project "…" 값이 2장에서 메모한 프로젝트 ID와 같다.
팁 · 「Updates are available… gcloud components update」와 「survey」 안내는 무시한다.
