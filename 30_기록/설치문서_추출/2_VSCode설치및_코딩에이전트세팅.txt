VS Code 기본 채팅에 Google Vertex AI(Gemini) 모델을 연결한다.
1번 문서(GCP 세팅)에서 확보한 프로젝트 ID 를 옆에 두고 시작한다.

한다. 끝나면 채팅창에 「이 파일 고쳐줘」라고 치면 AI가 폴더 안 코드를 직접 읽고 고친다.
이 과정에서 쓰는 확장은 이 문서에서 전부 설치하므로 뒤 문서에서는 확장을 더 깔지 않는다.

3장. 작업 폴더(워크스페이스) 열기
VS Code 채팅은 「지금 열려 있는 폴더」를 작업 공간으로 삼아 그 안의 파일을 읽고 고친다. 그래서 작업할 내용이 들어
있는 폴더 자체를 연다. 상위 폴더를 열면 AI가 매번 하위 폴더로 이동(cd)한 뒤 일해야 해서 엉뚱한 폴더에서 작업하거나
관계없는 파일까지 뒤진다.
5

주의 · 제한 모드에서는 아무것도 할 수 없다. 확장이 꺼지고, 채팅이 파일을 고치거나 명령을 실행하지 못하며,
