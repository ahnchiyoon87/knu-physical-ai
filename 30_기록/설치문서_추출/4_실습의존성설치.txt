실습 의존성 설치
파이썬 실행 도구 uv 를 설치한다.
파이썬 코드는 그냥 돌지 않는다. 파이썬을 깔고, 버전을 맞추고, 코드가 쓰는 부품을 하나씩
더 받아야 한다. 초보자가 제일 많이 막히는 자리가 여기다. uv 는 그걸 전부 알아서 한다. 우리
는 uv run 만 치면 된다. 2번 문서에서 연 VS Code 안에서 진행하며, 창을 따로 열 필요가 없
다.

1장. VS Code 터미널 열기
1
터미널 열기
2번 문서에서 연 VS Code 를 그대로 쓴다. 위 메뉴 터미널 → 새 터미널 (또는 Ctrl + ` ).
창 아래쪽에 명령 칸이 생긴다. 앞으로 나오는 명령은 전부 이 칸에 붙여넣는다. 직접 치지 않는다 — 한 글자만
틀려도 안 된다.
그림 1-1. 위 메뉴의 터미널 → 새 터미널
그림 1-2. 터미널 칸 — 여기에 붙여넣는다
확인 · 창 아래에 PS C:\Users\…> 로 끝나는 칸이 있다.
팁 · 창이 좁으면 터미널 메뉴가 … 안으로 접힌다. … 를 누르면 그 안에 있다.

2장. uv 설치
2
설치 한 줄 붙여넣기
아래 한 줄을 복사해 터미널 칸에 붙여넣고 Enter .
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | 
iex"
내려받기와 설치가 그 자리에서 이어진다.
그림 2-1. uv 설치 — 맨 아래 everything's installed! 로 끝난다
확인 · 맨 아래 everything's installed! 가 나온다.
3
터미널 닫고 새로 열기
방금 깐 것을 인식시키려면 필요하다. 터미널 칸 오른쪽 끝 휴지통 아이콘을 눌러 닫는다.
다시 터미널 → 새 터미널.
그림 2-2. 오른쪽 끝의 휴지통 아이콘을 눌러 닫는다
확인 · 새 터미널 칸이 열렸다.
4
설치 확인
새 칸에 아래를 붙여넣고 Enter .
uv --version
확인 · uv 0.… 처럼 버전 숫자가 나온다. 이 문서 끝.
화면이 다를 때 · 「uv 라는 용어가 인식되지 않습니다」 → 터미널을 안 닫고 그대로 쓴 것이다. 휴지통으로 닫
고 새로 연다. 그래도 안 되면 VS Code 를 완전히 껐다가 켠다.
