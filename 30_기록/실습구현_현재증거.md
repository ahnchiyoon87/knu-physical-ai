# 실습 구현의 현재 증거 · 제작 중

전체 강의 완료 기록이 아니다. 대본·가이드·출발본·일부 서비스 기능은 아직 제작 중이다.

- 신규 프로젝트: `10_실습/완성본/equipment-assistant`. 기존 본강 코드를 복사하지 않았다.
- Python 3.12.13 격리 환경에서 기본 의존성과 평가 의존성을 설치하고 `uv.lock`을 만들었다. CPU 모델·문서 인덱싱 모델은 내려받거나 실행하지 않았다.
- 최신 `langchain-community 0.4.2`와 RAGAS 0.4.3 조합은 `chat_models.vertexai` import 누락으로 실패했다. 실제 wheel과 의존 관계를 확인해 0.4.1로 고정한 뒤 RAGAS 네 지표와 생성 인터페이스 import에 성공했다. 유료 모델 호출은 없었다.
- `python -m pytest tests -q`: 21개 통과. SQL 허용/거부, 상태 이유, 표 머리글 청킹, 검색 순위 결합, 알람 억제, LOT 기준, 불균형 지표, 임계 도달 범위, API 접속·승인 권한·잘못된 입력만 확인했다. DB·모델은 연결하지 않았다.
- `ruff check backend scripts mcp_server --fix`: 후속 정리까지 지적 0. `compileall` 성공. 이후 변경에는 영향 범위 재확인이 필요하다.
- FastAPI 모듈 import 성공, 당시 등록 경로 29개. 경로 개수는 요구 기능의 동작 보증이 아니다.
- MCP 2.2.0 실제 설치 소스에서 `MCPServer.run_streamable_http_async`, `Client.call_tool`, `CallToolResult`의 인자/필드를 확인했다.
- 설치 PDF 4개의 텍스트를 추출했다(13·18·8·3쪽). 4번 문서는 uv 설치까지만 포함하므로 새 실습에서 Node·프로젝트별 설치·서비스 시작 설명이 추가로 필요하다. 2번 문서의 모델명·가격·권한 설명은 현행 검증 없이 신규 가이드에 복제하지 않는다. PDF 시각 전수 검수는 아직 하지 않았다.

미실행: 실데이터 수령·적재, DB 및 그래프 기동, 실제 모델 응답, 임베딩·비전·예측·RAGAS 모델 평가, 승인 흐름 완주, 학생 대역, GPU, 클라우드 배포, 외부 공유. 현재 합성 CSV는 원본 대신 조용히 선택하지 않고 별도 프로필로 표시한다.
