## 내용 검토에서 구별한 것

- 엑셀 상세 일정에 따른 이론 합계는 76H다. 오프라인 21개 행은 합동 OT가 두 반에 포함된 집계이며 서로 다른 날짜 21개를 의미하지 않는다. 반별 인정시간 합계는 80H다.
- ZIP의 60분 시연 배분은 매 영상마다 완성 서비스 전체를 다시 시연하는 방식으로 확대하지 않았다. 해당 단계의 적용 장면과 판단을 설명하는 원고로 구성했다. 실제 실행 화면을 찍었다고 쓰지 않았다.
- 원자료 R5의 행 수·라벨·이미지 크기는 패키지에 담긴 조사 기록이다. 원시 데이터 전체를 다시 읽어 측정한 값으로 표현하지 않았다.
- 시간 열 없는 샷 순서와 경과시간, 그래프 관계와 확정 원인, 이상 점수와 확률, 합성 임계값 도달과 실제 잔여수명을 구별했다.
- 평가 덱은 검색 정밀도·검색 재현율·응답 관련성·근거 지지를 구별한다. 모델 심사를 정답 판정기로 단정하지 않는다. RAGAS 지표마다 계산 정의가 다를 수 있음을 명시했다.
- 실전반 영상8 S15 이후와 통합반 영상11은 데이터 재생·승인된 기록 및 규칙 변경까지를 수업의 폐루프로 잡았다. 실제 설비 자율 제어가 구현된 것처럼 확대하지 않았다. 승인 대상·버전·재개·중복 기록의 의미를 나누었다.
- 통합반 영상9의 배포 단계와 영상10 이후의 승인 기능을 구별하고, 마지막 실습일에 영상10·11이 연결됨을 일정에 반영했다.
- 공식 기술 문서로 확인한 설명은 해당 덱에 출처를 붙였다. 모델 이름·가격·실행 성능은 추정하여 채우지 않았다.

## 확인의 실제 범위

공통 내용 단위와 주요 개념 경계, 반별 연결, 대표 장의 화면 문장과 제목을 검토했다. 별도 검토자가 1,170장을 독립적으로 전수 감수한 결과는 아니다. 모든 파일의 번호·필수 항목·시간·분할 동일성·일정·로컬 링크·해시는 자동 대조했다. 결과는 120항목 통과, 실패 0이다.

장 수와 시간은 제작 계획이다. 실제 발화량으로 4시간이 되는지, 생성 PPTX가 읽기 좋은지, 삽화가 정확한지는 측정하지 않았다. NotebookLM에서 첫 분할을 만든 뒤 화면 문구·삽화·전환을 원고와 대조하고 낭독 시간을 확인해야 한다. 원고가 많으므로 전체를 한 번에 요약 생성하지 않도록 분할입력을 제공했다. 분할당 12장은 검토 단위이며 서비스의 공식 한도라는 뜻이 아니다.

실습코드·출발본·일차별 실행 가이드·낭독 대본·합동 OT 현장 덱은 후속이다. 설치 PDF 내용 재검증, 유료 API 호출, GPU 실행, 학생 방식 대역 완주, PPTX 렌더, 외부 업로드·공유는 수행하지 않았다. 원본 ZIP·HTML·설치 PDF 4개·리허설 PPTX의 해시 7개는 변경 전과 같다.
