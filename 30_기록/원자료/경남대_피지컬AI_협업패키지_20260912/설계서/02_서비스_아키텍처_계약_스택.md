# 02 · 서비스 아키텍처 · 계약 · 스택 (정본)

## 1. 학생 서비스 「설비 이상 대응 어시스턴트」 — 5계층 학생판
저장소 하나. `frontend/`(Vue 3) + `backend/`(FastAPI) + Supabase(로컬 Docker) + 그래프DB(로컬). 층 이름 = 폴더 이름. 각 층에 `gateway.py`(밖으로 나가는 호출 한 곳)와 `service.py`는 반드시 있고 나머지 파일명은 자유.

| 층 | 폴더 | 학생판 구성요소 | 붙는 회차 |
|---|---|---|---|
| ① 데이터 | `backend/data` | CSV 업로드 → Supabase 테이블(중복 방지) · mapping 다원천 · 우리말 질문 → SQL(열은 번호로 · 정찰 SQL · LOT 앵커 · 요구사항 체크리스트 O/X/모름 → 합격은 코드 · 최소 변경 수리 · 결정론 감점 · 실패 = 「답변 실패」) · 파싱 검사 + 실행 계층 행 제한(SQL 무변경) · 출처(lineage) | 실1·2·3 |
| ② 온톨로지 | `backend/ontology` | `ontology/ontology.csv`(클래스·관계·키) · 그래프 적재/조회 게이트웨이 · 회차마다 노드 종류 추가 | 실1 → 전 회차 |
| 판단 | `backend/detect` | 규칙(절대·상대·조합)·알람 우선순위/억제 · PyOD·Chronos-Bolt · 판별(표)·Anomalib(비전)·예지보전 · 결과는 전부 그래프 노드 | 실4·5, 통2·3·5·6 |

## 2. 계약 — `constitution.md` (실물은 `뼈대초안/constitution.md`)
정체·층·API 주소 목록·응답 JSON·출처 형식 3종·상태 값(`ok/none/refused/failed/error/pending_approval/insufficient`)·설정 위치(`mapping.json`·`config.yaml`)·관측 규범·불변 원칙·금지. 200줄 미만. 과정·수업·인원 언급 없음.

## 3. 작업 규범 — `AGENTS.md` (실물은 `뼈대초안/AGENTS.md`)
답변 우선 세 줄 · 착수 관문(배선 한 줄·영향도) · 폴더·이름·로그 형식 · 원인 찾기 7단계(모델은 마지막 용의자) · 코드 규범 · 종료 감사 · 스킬 라우팅 표 · 읽는 순서. 200줄 미만.

## 5. 스킬·스크립트·규칙
- 주는 스킬 2: `debug`(원인 찾기 7단계, 산출물 강제) · `spec`(6단계).
- 학생 스킬 3(회차 지정): `leave-notes`(실3) · `ontology-extend`(실6) · `verify-property`(실7). 계약 표면만 만진다(파일명·함수명 금지).
- 스크립트 3(학생이 spec으로 만듦): `scripts/reload.py`(실5) · `scripts/eval.py`(실7) · `scripts/deploy.sh`(통9). + `scripts/data_check.py`(우리가 줌).
- 규칙(`.agent/rules/`, 파일 열 때 켜짐): `code.md`(코드 규범) · `log.md`(로그 형식) · `ontology.md`(확장 절차) · `tests.md`(성질→검사) · `skills.md`(스킬 저작 규격: 발동 문구 예시 6~8·계약 표면만·500행 미만) · `infra.md`(학생 프롬프트가 말하지 않아도 헌법대로 만드는 것: 마이그레이션·인덱스·해시·읽기 전용 실행·행 제한·멱등·트랜잭션 되읽기).
- 장치 카드(`.agent/cards/`): 정본 HTML 표와 1:1. 한 장 = 실패/무엇/언제 쓰고 안 쓰나/우리 데이터로 만드나/자사 제품 어디.
- 메모리(`.agent/`): `decisions.md` · `invariants.md`(층·단계별 입력/출력 조건) · `failures.md`(증상·처음 깨진 단계·분류·고친 자리).

## 6. 관측 규범 (디버깅이 되게 하는 전제)
```
{"ts":"…","rid":"r-8f3a","layer":"rag","step":"router.select","in":{...요약만},"out":{...요약만},"ms":18,"status":"ok","loc":"backend/rag/router.py:select"}
```
`rid` 요청당 하나, 층·단계는 `AGENTS.md` 목록에서만, `loc`은 파일:함수, `in/out`은 길이·개수·ID만, `status`는 계약 값, 실패엔 `reason`. 게이트웨이가 로그를 남긴다. `print` 금지. `/health`는 층별 상태 + 회차 번호별 전제 라우트, `/trace/{rid}`는 그 요청 줄들.

## 7. 저장소·출발본 정책
- 학생 저장소 = GitHub 개인 저장소(특강에서 생성). 회차 끝 커밋·push. 되돌리기는 git.
- 우리 완성본 저장소에 회차 태그 `실N-start`/`통N-start`. 출발본 = 그 태그.
- 매 회차 출발 검사 5줄(`/health`): 서버·계약 라우트·화면·오늘 전제·커밋. 다 초록 → 자기 것. 아니면 `-내작업`으로 옮기고 태그를 받는다. 첫 회차는 전원 뼈대.
- 뼈대(첫 회차): `constitution.md` `AGENTS.md` `mapping.json` `data/` `ontology/ontology.csv`(빈 표) `.agent/`(스킬 2·규칙·빈 메모리) `.gitignore`(`.env`·데이터·모델) `README`. 코드 0줄, 좌표 0.
- 공유 자원은 API 키 + 사내 모델 주소. Supabase·그래프·MCP·로그는 전부 로컬.
