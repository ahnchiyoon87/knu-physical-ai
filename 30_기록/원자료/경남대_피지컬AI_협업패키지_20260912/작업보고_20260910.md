# 작업보고 — 2026-09-10

## 오늘 한 것 한 줄
수업에서 다룰 "공장 이야기"를 상상이 아니라 **실제 공장 자료와 실제 데이터**로 다시 세웠습니다.

## 1. 이야기를 실물로 바꿨다
- 전에는 우리가 지어낸 공장 이야기였습니다. 근거가 없어서 버렸습니다.
- 지금은 실제 사출 공장이 스스로 적어 놓은 문제(불량이 많다 / 원인 찾기 어렵다 / 해결 방법이 기록에 안 남는다 / 기계 조건을 감으로 맞춘다 / 부품이 식은 뒤에야 불량인 걸 안다), 실제 현장 서류(조건 기록표·작업일지·인수인계서·변경 신고서), 실제 고장 방식(갑자기 튀는 것 / 서서히 변하는 것)을 그대로 씁니다.
- 문서의 모든 문장에 표시를 붙였습니다 — **근거**(자료에 있는 것) / **설계**(우리가 정한 것) / **합성**(데이터에 우리가 심은 것). 표시 없는 문장은 없습니다.

## 2. 제조를 모르는 사람도 알게 배경을 먼저 만들었다
- 사출기가 무슨 기계인지, 한 번 찍는 게 뭔지, 기계가 남기는 숫자 26가지가 언제 찍히는지, 공장 사람들이 하루를 어떻게 일하는지 — 그림 10장과 표로 풀었습니다.
- 이게 먼저 있어야 학생이 뒤에서 "AI가 왜 이 자료를 찾는지"를 압니다. 지금은 학생도 강사도 제조를 몰라도 읽힙니다.

## 3. 부족한 부분을 자료 조사로 채웠다
현장에서 실제로 쓰는 서류의 항목, 교대 근무의 순서, 기계·재료·방법을 바꿀 때 누가 결재하는지, 불량 종류별 원인과 대책 자료, 기계 회사가 제공하는 감시 기능, 경남 지역 스마트공장 성과.

## 4. 진짜 데이터를 받아서 확인했다
- **KAMP**는 중소벤처기업부가 KAIST에 맡겨 운영하는 사이트입니다. 실제 공장 데이터를 무료로 공개합니다(회원가입, 출처 표기 필요). 이름에 AI가 붙지만 내용은 숫자 표와 설명서입니다.
- 거기 있는 50종을 전부 대조해 보니, **센서 숫자 + 양품/불량 표시 + 사진이 한 업종에 다 있는 곳은 사출성형뿐**이었습니다. 그래서 사출기로 정했습니다(우리 취향이 아니라 데이터가 그렇게 있어서).
- 받은 것 세 벌: ① 사출기 한 대의 100만 번 기록(설비 부품 지도까지 딸려 옴) ② 양품/불량 표시가 있는 사출 데이터 ③ 같은 제품을 열화상 카메라로 찍은 사진 837장(양품 616·불량 221).
- **AI-Hub**는 정부가 운영하는 또 다른 데이터 공개 사이트입니다. 자동차 부품 사진을 확인했지만, 사출 열화상이 나와서 지금은 예비로만 둡니다.
- 데이터를 직접 열어 확인한 것: 갑자기 튀는 고장은 실제로 들어 있고, 서서히 변하는 것은 약하게 하나 있음. 설비 부품 지도가 들어 있어 첫 수업의 "공장의 지도" 만들기가 지어낸 표가 아니라 실물에서 시작함.

## 바뀐 것
- 사진 수업: 자동차 부품 사진을 빌리려던 것 → 사출 제품 열화상으로. 한 공장으로 통일됨.
- 판별 수업: 제품 양품/불량 + 설비 정상/비정상, 두 가지를 다 다룸.
- 잡음 수업: 데이터에 실제로 있는 문제(값이 전부 0인 열, 튀는 값, 표기가 서로 다른 것)를 씀.
