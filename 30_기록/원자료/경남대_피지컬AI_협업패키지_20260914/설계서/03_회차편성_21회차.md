# 03 · 회차 편성 — 21회차 + 특강 (요약 · 정본은 `실습흐름_정본.html`, 표는 `실라버스_21회차.md`)

**갱신 2026-09-14.** 날짜·시수 고정, 제목·내용은 우리 제안(엑셀 제목은 초안이었음). 셋이 다르면 HTML이 이긴다.

**틀(고정)** 출발 20분 · 블록 4 × 50분 · 닫기 20분. 출발 = /health 5줄 → 자기 것 또는 출발본 → 다른 점 하나 → 영상 과제. 블록 = 퀴즈(상황·문제·힌트·빈칸·됐는지). 모델 블록 = 루프 여섯. 닫기 = 세 줄(판단·한계·옮겨 보기). 인프라는 에이전트가 헌법대로. 억지 페인포인트 없음.

## 순서와 이유
센서 신호(실1) → 데이터 품질(실2) → 타임시리즈 분석(실3) → 온톨로지·데이터 패브릭(실4) → 이상감지·파이프라인(실5) → 문서 RAG(실6) → 평가·모델 둘(실7) → 에이전트(실8) → 적용·다른 주제(실9).
- 관계표는 실1 손으로 → 매 회차 한 줄 → 실4 그래프DB·스킬. 이후 알람·판정·조치가 점으로 붙는다.
- 패브릭은 실2 다원천 + 실3 계보가 실4에서 한 카탈로그·한 접근으로. 실9 갈아 끼우기의 근거.
- 시계열은 실3 분석 → 실5 탐지 → 통5 예측. 실3 상관(쿠션↔계량시간)이 실5 조합 규칙의 근거.
- 에이전트는 실4 길 찾기 → 실5 파이프라인 → 실7 라우터 → 실8 잇기.
- 문서 RAG가 실6인 이유: 그래프와 알람이 있어야 「알람의 원인」을 표→문서로 건넌다.
- 스킬 셋: 3회 뒤 4회째 — leave-notes(실3/통3), ontology-extend(실4/통4), verify-property(실7/통8).
