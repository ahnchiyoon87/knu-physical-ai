# 04 · 실습가이드 작성 규격 (정본 · 2026-09-12)

한 회차 = `40_가이드/실N_회차명.md`. 공유 회차는 복사 + 반별 도입 문장만.

## 1. 구조 (위에서 아래로 한 방향)
```
# 실N · 회차명(엑셀 원문)
왜 오늘 — 현장 근거 1~2줄([근거/설계/합성] 라벨) + 서비스 관점 1줄
어제까지 있는 것 / 오늘 끝나면 — 각 한 줄
오늘의 말 — 모델·에이전트 쪽 용어만(조각·근거·컨텍스트·체크리스트·앵커·리랭크·노드…). 인프라 용어 없음
에이전트가 헌법대로 만든 것 — 한 줄(마이그레이션·인덱스·해시·읽기 전용·로그…). 설명하지 않는다
출발 (20분)
블록 1~4 (50분씩) — §2 퀴즈 형식
닫기 (20분) — 캡처·커밋·push·되돌린 것·세 줄·열린 결말
```
「안 될 때」 표·「대비」 상자는 학생 가이드에 없다(강사용 파일 `40_가이드/강사용/실N_대비.md`).

## 2. 블록 형식 (고정 · 퀴즈)
```
### 블록 N · 제목
상황 — 실데이터·실제 도구 동작에서 나온 것만. 지어낸 상황 0
문제 — 학생이 정할 것을 한 문장으로
[명세를 쓴다] (실3/통2부터) — 「무엇으로 잰다」가 「무엇을」보다 먼저
어떻게 시킬까?
    -- 힌트 (회차별 줄 수: 실1·2 3 / 실3~5·통2~6 2 / 실6·7·통7~9 1 / 실8·9·통10 0~1)
[학생이 프롬프트를 쓴다]
(장치 카드 — 있을 때만. 실패/무엇/언제/자사 제품 어디. 실1~5는 한 장 지정, 실6부터는 묶음에서 학생이 고름)
됐는지 — 화면에서 확인 가능한 것 + 채점표 버전
```
모델을 부르는 블록은 반드시 「잰다」가 있다(질문셋·채점표·전/후). 힌트는 방향·어디를 보라이지 프롬프트 문장이 아니다. 완성 프롬프트 0줄.

## 3. 힌트 규칙
- 세기: 실1·2 「어디를 보라」 → 실3~5 「무엇 기준인가」 → 실6·7 「종류를 갈라 보자」 → 실8·9 채점표만.
- 시간으로 여는 힌트 없음. 강한 힌트·정답은 가이드에 없고 강사가 단톡방에서 준다. 가이드에 「단톡방」 문구도 없다.
- 회차 뒤 실제로 나온 질문을 강사용 대비 파일에 쌓는다 — 다음 판 가이드의 수정 근거.

## 4. 용어
영어 용어 그대로 → 한 문장 뜻 → 왜 한 줄 → 비유는 필요할 때 하나. 모델·에이전트 쪽만. 인프라 용어(마이그레이션·인덱스·HNSW·멱등·체크포인트)는 가이드에 설명하지 않는다.

## 5. 캡처
실제 완성본 화면. 회차당 4~8장. `실N-B2-03_무엇.png`, 폭 ≥1280, 키·개인정보 없음. 본문에 데이터 값 금지.
