# 전체 제작 작업계획

2026-09-14 현행화. 목표는 상세 이론 덱·온라인 이론 대본·일차별 실습가이드·신규 실습코드와 단계별 출발/완성본 전체다. 통합반과 실전반(4학년)의 내용은 같고 원본 일정별 묶음만 다르다. 덱 단계 완료를 전체 완료로 세지 않는다.

## 제작 순서와 현재 위치

| 순서 | 작업 | 상태/후속 |
|---|---|---|
| 1 | 원자료·일정·최신 지시 연결 | 반 명칭과 영상/실습 시수 확인. 날짜 보존. 원자료 해시 7개 재확인 |
| 2 | 신규 서비스와 교육용 자료 작성 | 전체 앱 작성, 제한된 경계 검사·프런트 빌드 통과. 요구 완결성 검토 중 |
| 3 | 두 반 공통 수업으로 전환 | 공통 이론 8단위, 영상별 8/11편, 실습 14단위의 9/10일 묶음 작성 |
| 4 | 출발본·일차 완성본·학생 묶음 | 현재 공통 코드 ZIP 38개·학생 ZIP 19개 작성 및 구조/단계/링크 검사 |
| 5 | 설명과 실습의 의미·분량 보완 | 진행 중. 반복 적용 대본, 전 장 흐름, 편별 시간, 복합 실습일 부담과 코드 요구 대조 |
| 6 | 영향 파생물·문서와 제한된 검사 갱신 | 변경 범위마다 수행. 현재 파일 목록은 공통 인덱스, 미결은 별도 문서로 유지 |
| 7 | 전체 최종 보고와 공유 | Git 공유는 완료되어 후속 변경도 push. 전체 최종 완료/보고는 수용 기준 충족 후 |

## 유지할 구현 결정

- 앱은 `equipment-assistant`. 기존 본강 코드를 그대로 승계하지 않는다.
- 표·영속 기록·벡터는 Postgres/pgvector, 관계는 Neo4j다. 설치 실측이나 실행 성능을 확인한 결정으로 표현하지 않는다.
- `mapping.json`이 원천·열 뜻·단위·키·라벨·문서 상태의 진입점이다. 합성 입력을 원본 대신 조용히 선택하지 않는다.
- 일반 서비스, CPU 모델, 문서 인덱싱, 평가 의존성을 구분한다. 모델 이름 추정·무단 대체·시작 시 유료 호출을 허용하지 않는다.
- Postgres와 그래프를 하나의 원자 트랜잭션처럼 표현하지 않는다. 그래프 작업을 영속 기록하고 멱등 반영과 오류 재확인을 둔다.
- 학생 코딩 지시와 서비스 모델 지시를 분리한다. 자신의 구현·질문·판단을 남길 수 있게 하며 완성 프롬프트 복사만으로 끝내지 않는다.
- 합류 시 기존 폴더를 보존하고 이전 단계 출발본을 새 폴더에서 연다. `git reset --hard`를 학생 기본 복구로 쓰지 않는다.
- 학생 감시·노트 제출 의무·미시청자 제한을 추가하지 않는다. 가이드에서 현재 행동의 이유와 확인·복구를 설명한다.
- 실제 설비 조작과 소프트웨어 규칙 기록/재생을 구별한다. 확인하지 않은 화면을 실제 캡처처럼 만들지 않는다.

[요구반영표](요구반영표.md)에 산출물과 한계, [현재 미결](전체제작_현재미결.md)에 다음 행동, [현재 인계](../00_문서/0_인계.md)에 경로·증거·편집 주의를 둔다. 실행 제한은 제작 생략 근거가 아니다. 현재 자료를 고치는 생성 도구는 먼저 매니페스트와 수작업 편집을 확인한다. 원자료·과거 ZIP·Git 이력을 보존한다.
