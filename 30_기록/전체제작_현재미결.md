2026-09-14 갱신. 전체 goal 진행 중. 현재 파일 목록과 제한된 검사 근거는 [인계](../00_문서/0_인계.md), 요구별 판정은 [요구반영표](요구반영표.md)에 둔다. 완료된 공통 전환과 Git 공유를 다시 미결로 적지 않는다.

## 해결되어 다시 대기하지 않는 항목

- 원본 엑셀로 실전반=4학년을 확인했다. 반 명칭 추가 답변은 필요 없다.
- 공통 8단위 원고와 영상별 8편/11편 제작본을 만들었다. 두 반의 장면과 발화 전체 순서가 같다.
- 공통 19일 가이드, 단계별 출발 19·완성 19, 학생 시작 ZIP 19를 만들고 검사했다. 현재 목록은 각 공통 README와 매니페스트다.
- 파이프라인 이론이 실전 4일차보다 늦던 배치를 수정했다. 명시한 36개 핵심 주제에서 늦은 공개 0건이다.
- 전체 자료는 요청한 GitHub 저장소에 공유했다. `.env`·인증 정보는 제외한다. Git 공유와 강의 전체 완료를 구분한다.
- 원본 해시 7개는 현재 재확인에서도 그대로다. 생성 원천 44개는 내용 대조를 마쳤다.

## 외부 대기와 실행 범위

실제 KAMP·열화상·C-MAPSS의 보유 경로는 사용자 응답 대기다. 교육용 합성 자료를 실제 원본으로 표시하지 않는다. 이 대기 때문에 다른 집필·코드·구성 작업을 멈추지 않는다.

유료 모델·GPU·학습·가중치 다운로드·DB 업무 실행·학생 완주는 사용자 지시로 제외한다. 설치 PDF의 현재 설치 성공, 모델 성능, 실제 낭독 길이, PPTX 화면 품질은 미검증이다. CUA 브라우저가 없어 앱 화면 육안 확인도 미검증이다. 실행하지 않은 것은 실패 결과나 통과로 만들지 않는다. Google Drive/ESNS 전달은 미수행이며 Git 공유 승인을 해당 메시지 발송 승인으로 확대하지 않는다.
