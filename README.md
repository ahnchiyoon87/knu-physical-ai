# 경남대 피지컬 AI 강의 리뉴얼

팀 공동 제작 저장소입니다. 이론·실습·가이드·코드·원자료와 제작 기록을 함께 관리합니다. **현재 제작 중이며 전체 강의 준비가 완료된 상태는 아닙니다.**

실전반은 4학년, 통합반은 2·3학년입니다. 두 반은 같은 내용을 배우고 일정별 묶음만 다릅니다. 대본은 온라인 이론에만 필요합니다. PPTX는 상세 Markdown 덱을 NotebookLM에 입력해 제작하는 방식입니다.

기존 반별 덱·대본·가이드·ZIP은 보존된 제작 기록입니다. 공통 순서의 출발본과 기존 반별 출발본을 혼용하지 않습니다. 공통 수업 시작 ZIP은 19개를 생성해 구성·링크·출발 코드 일치를 확인했습니다. 전체 의미·시간 검토 등은 진행 중입니다.

## 폴더

| 경로 | 내용 |

원본 ZIP과 HTML도 보존합니다. 제작 로그의 과거 절대경로는 작성 당시의 근거이며, 저장소를 다른 위치에 복제했을 때 실행 경로로 사용하지 않습니다.

## 팀 작업

1. 이 저장소를 복제하고 현재 인계와 제작 기준을 읽습니다.
2. 새 브랜치에서 작업합니다. 기존 원자료와 다른 작업자의 편집을 보존합니다.
3. 생성 도구를 실행하기 전 입력 원고와 매니페스트, 수정 범위를 확인합니다. 생성된 파일의 수작업 편집을 덮어쓰지 않습니다.
4. 변경한 내용과 실제 검사 범위를 커밋에 남깁니다. 전체 완주를 하지 않았다면 완주했다고 표시하지 않습니다.

`.env`, 인증 파일, 가상환경, 설치 캐시와 로컬 빌드 결과는 Git에서 제외합니다. `.env.example`과 의존성 잠금 파일은 포함합니다. 실제 계정 정보는 각자의 로컬 환경에서 설정하고 ZIP이나 커밋에도 넣지 않습니다.

이 저장소의 검사는 구문·구성·API import 등 제한된 확인입니다. 유료 모델 호출, 가중치 다운로드·GPU 학습, DB 업무 실행과 학생 실습 완주는 이번 제작 과정에서 수행하지 않았습니다. 합성 자료를 실제 공장 측정 결과로 표시하지 않습니다.
