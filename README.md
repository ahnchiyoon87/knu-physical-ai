가벼운 준비 검사: 이 폴더에서 `python 제작도구/check_preparation.py`를 실행합니다. 입력 구조·추출기·Python 문법을 확인하며 컨테이너·모델·학생 실습 완주를 실행하지 않습니다. 플랫폼 실행 안내는 플랫폼코드/LOCAL_SETUP.md에 있습니다.

온라인은 이론자료/1회차, 오프라인은 실습자료/1일차처럼 회차에만 숫자를 씁니다. 두 반의 공통 자료는 복제하지 않고 편성표에서 연결합니다. 플랫폼 코드 내부의 영문 폴더명은 유지합니다.
