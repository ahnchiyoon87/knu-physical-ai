# 온라인 1회차 영상 구성

## 제작 기준

- 대상: 실전반 온라인 1회차(실V1), 제출 마감 2026-09-25. 통합반의 별도 편성은 복사로 확정하지 않는다.
- 사용자 확정: 이론 영상 합계240분, 영상 한 편 최대20분. 오프라인 실습은 별도다.
- 아래12편×20분은 제작 목표다. 사용자가 PPTX를 보며 마이크로 직접 강의하고 녹화한다. 에이전트는 PPTX·대본을 준비하며 녹화 후 실제 재생시간과 피드백을 반영한다.20분을 넘는 편은 주제 경계에서 나누고, 짧아진 분량은 필요한 개념·예시·해설로 보완한다. 재생속도 낮추기·정지 화면 늘이기로 총시간을 채우지 않는다. 실제 편수는12편보다 늘어날 수 있다.
- 각 편의 영상+PPTX를 하나의 컨펌 단위로 만든다. 첫 단위의 피드백 반영 전에 나머지 영상을 일괄 완성하지 않는다. 외부 공유는 사용자 수행이다.
- 첫 검토 묶음에는 이 회차 전체의 편별 목차·목표시간과 첫 영상·해당 PPTX를 함께 준비한다. 기존 커리큘럼을 재설계하는 절차가 아니라 회차 내용을 영상으로 나누는 방식과 설명 수준을 확인하는 절차다. 대본은 제작용으로 보관한다.
- 기존 `관측과출처_덱.md`17장과 대응 대본은 재사용할 설명 재료이며240분 완성본이 아니다.

## 범위와 연결

P01 교재의 B1·B2·B3 및 첫날 제공 과제를 토대로 한다. V1-01의 전체 시스템은 위치를 알려주는 개요이며 B4 이후의 구현을 앞당기지 않는다. V1-09는 기존 P01에서 사용하는 제공 품질 결과를 읽는 내용으로, P02의 오류 주입·규칙 수정·품질 판정 심화는 다음 회차에 남긴다. Python 문법은 주기·집계·레코드·조회 결과를 이해하는 곳에서 설명하고 코딩 에이전트에게 구현을 맡기는 확정 방향을 따른다.

이 영상 묶음은 P01 실습 하루를 녹화한 것이 아니다. 온라인에서는 개념·비교·설계 판단을 설명한다. 오프라인에서 학생은 직접 실행하고 관찰하며 자기 결과를 확인한다. 같은 개념을 사용하더라도 이론 영상 한 편과 실습 활동 하나를 일대일로 강제하지 않는다.
