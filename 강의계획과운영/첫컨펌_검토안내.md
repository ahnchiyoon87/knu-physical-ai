# 첫 컨펌 자료

온라인 이론의 설명 수준과 영상 분할 방식, 오프라인 실습의 안내 방식을 확인하기 위한 첫 검토 자료입니다. 이론과 실습은 별도이며 영상 한 편과 실습 하루를 일대일로 맞추지 않습니다.

## 온라인 이론

| 자료 | 확인할 내용 |
|---|---|
| [온라인 1회차 영상 구성](온라인1회차_영상구성.md) | 확정된 회차 주제 안에서 240분을 최대20분 영상으로 나누는 목차와 목표시간 |
| [첫 영상 PPTX](../이론자료/1회차/영상01/제조데이터와판단.pptx) | ‘제조 데이터를 판단으로 연결하는 시스템’, 11장. 다운로드해 PowerPoint로 확인 |
| [첫 영상 대본](../이론자료/1회차/영상01/제조데이터와판단_온라인대본.md) | PPTX와 같은 순서의 설명. 발표자 노트에도 포함 |

영상은 강사가 직접 설명하며 촬영해 추가 전달합니다. 첫 편은 20분 목표이며 실제 녹화시간은 아직 측정하지 않았습니다. 나머지 영상의 본 제작은 첫 검토 의견을 반영한 뒤 이어갑니다.

## 오프라인 실습

**[관측에서 원본까지 — 실습가이드](../실습자료/1일차/관측에서원본까지_실습가이드.md)**

센서 파일 읽기 → 같은 1초 구간으로 정리 → 원본 대조 → 여러 사이클 연결 → 저장·재조회까지 다룹니다. 실제 실행 화면을 포함하며, 필요한 개념을 각 행동 앞에서 짧게 설명합니다. 설치·구현은 코딩 에이전트가 수행하고 학생은 요구와 실제 결과를 확인합니다.

- [시작 파일](../실습자료/1일차/원문시작본): 반에 맞는 파일을 개인 작업 폴더에 복사해 사용합니다.
- [환경 준비](../플랫폼코드/LOCAL_SETUP.md): 코딩 에이전트가 준비할 로컬 실행 조건입니다.
- [완성본](../실습자료/1일차/완성본): 검토·합류용입니다. 시작 파일과 함께 학생에게 정답으로 배포하지 않습니다.

실전반의 DB 적재·조회와 통합반의 노트북 실행·CSV 저장 결과를 확인했습니다. 학생이 코딩 에이전트와 처음부터 끝까지 수행하는 완주·소요시간·비용은 강사 실습 후 확인합니다. 중앙 중계의 모델 호환성 검증과 최종 학생 설치 안내는 남아 있습니다.

## 검토 요청

첫 영상의 설명 깊이와 용어 도입, 회차 내 영상 분할, 실습가이드의 행동·관찰·판단 안내가 적절한지 확인 부탁드립니다. 의견을 반영해 같은 기준으로 후속 자료를 제작하겠습니다.
