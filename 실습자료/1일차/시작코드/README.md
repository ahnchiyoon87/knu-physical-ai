# 첫날 작업 폴더

`data/sensor_windows.json`은 실제 UCI 원본에서 뽑은 작은 표본이다. 3개 센서, 3개 사이클의 첫 3초를 포함한다. 센서마다 1초에 재는 횟수가 다르다. 원본과 출처 정보를 수정하지 않는다.

코딩 에이전트는 아래 요구를 먼저 짧게 설명하고 `student-work/` 안에 구현한다. 학생이 Python 파일이나 JSON을 직접 작성하도록 요구하지 않는다.

- 입력: `data/sensor_windows.json`의 각 1초 구간.
- 출력: 센서·원본 사이클·사이클 내 초·단위·평균·최솟값·최댓값·개수의 표.
- 원본 측정값을 읽어 계산한다. 예시 숫자를 결과로 하드코딩하지 않는다.
- 데이터가 비었거나 개수가 hz와 다르면 해당 구간을 오류로 알려 준다. 0으로 채우거나 조용히 버리지 않는다.
- 실제 수집 시각이 없는 표본에 임의 날짜를 붙이지 않는다.
- 센서별 단위를 유지한다. 평균만 남기고 범위·개수·출처를 버리지 않는다.
- 결과를 학생이 볼 수 있는 CSV 또는 로컬 화면으로 제공하고 입력과 비교할 구간을 알려 준다.

완성 코드가 없는 것은 누락이 아니다. 이 폴더에 들어 있는 실제 표본과 요구사항을 바탕으로 코딩 에이전트가 첫 기능을 만든다. 플랫폼 전체는 별도로 제공한다.
