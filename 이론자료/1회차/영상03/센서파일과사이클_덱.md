# 표시된 숫자를 원본에서 다시 찾기

## S01 이 값은 어디에서 왔을까

**TS1 · 53.219°C**

실제 제공 파일: `TS1.txt` / 코드의 사이클100 / 첫 번째 샘플

값의 의미를 읽었다면, 이제 그 값의 위치를 찾습니다.

## S02 센서 이름에서 파일로 들어간다

```text
TS1 → TS1.txt → 온도
PS1 → PS1.txt → 압력
FS1 → FS1.txt → 유량
```

`SENSOR_SPEC`의 파일 연결을 확인합니다.

파일을 찾았다고 원하는 관측까지 찾은 것은 아닙니다.

## S03 반복 운전 한 번을 사이클로 묶는다

```text
60초 운전 → 60초 운전 → 60초 운전
  한 묶음      다음 묶음      다음 묶음
```

제공 UCI 실험은 60초의 운전 구간을 반복합니다.

**사이클:** 이 데이터에서 운전 한 번의 기록을 묶는 단위

실제 공장의 모든 반복 운전이60초라는 뜻은 아닙니다.

## S04 한 줄은 한 사이클의 여러 값

| 파일 안 위치 | 첫 샘플 | 다음 샘플 | 이어지는 샘플 |
|---|---:|---:|---|
| 첫 줄 · 사이클0 | 35.570 | 35.492 | … |
| 101번째 줄 · 사이클100 | 53.219 | 53.207 | … |

TS1 원본 일부입니다. 점 세 개는 생략이며 원본 값이 아닙니다.

행을 바꾸면 다른 사이클, 같은 행 안에서 이동하면 그 사이클의 다른 샘플입니다.

## S05 숫자 사이의 경계를 읽는다

```text
53.219  [탭]  53.207  [탭]  53.148  [탭]  53.07 …
```

`[탭]`은 눈에 보이지 않는 구분자를 설명하기 위한 표시입니다.

탭: 같은 줄의 값을 나눔 / 줄바꿈: 다음 사이클로 이동

텍스트가 자동으로 화면에서 접혀 보이는 것과 실제 줄바꿈을 구분합니다.

## S06 첫 줄부터 데이터가 있다

원본 센서 파일에는 열 이름을 적은 머리글이 없습니다.

| 읽기 가정 | 확인할 위험 |
|---|---|
| 첫 줄을 데이터로 읽음 | 제공 원본의 구조에 맞는가 |
| 첫 줄을 열 이름으로 읽음 | 첫 사이클이 데이터에서 빠지지 않았는가 |

실제 확인: 세 센서 파일 모두 **2,205행**

## S07 첫 위치를 0으로 세는 약속

| 사람이 세는 파일 줄 | 코드의 사이클 인덱스 |
|---:|---:|
| 1번째 | 0 |
| 2번째 | 1 |
| 100번째 | 99 |
| 101번째 | 100 |

인덱스: 목록에서 항목의 위치를 가리키는 번호

이 원본처럼 머리글·빈 줄이 없는 경우 **파일 줄 = 인덱스 + 1**

## S08 실제 값으로 한 줄 차이를 확인한다

| TS1 원본 | 첫 값 |
|---|---:|
| 100번째 줄 / 사이클99 | 53.324°C |
| 101번째 줄 / 사이클100 | 53.219°C |
| 102번째 줄 / 사이클101 | 53.379°C |

값이 비슷해 보여도 다른 원본 위치입니다.

숫자의 그럴듯함보다 **파일·사이클·위치의 대응**을 확인합니다.

## S09 문자로 읽은 값을 숫자로 해석한다

```text
파일의 한 줄 → 탭으로 나눈 문자열 → 숫자로 해석한 샘플 목록
```

숫자형: 값을 수치로 계산·비교할 수 있게 표현하는 방식

변환하지 못하는 항목이 있다면 해당 위치와 원문을 확인합니다.

읽지 못한 값을 임의의0으로 바꾸지 않습니다.

## S10 요청한 사이클을 읽었는지 확인한다

```python
read_raw_cycle("TS1", 100)
```

제공 함수 호출: 온도 파일의 코드상 사이클100을 읽습니다.

확인할 결과: 파일101번째 줄 · 샘플60개 · 첫 값53.219

이 호출은 DB 저장이나 관제 갱신까지 수행하는 명령이 아닙니다.

## S11 같은 사이클인데 값의 개수가 다르다

| 센서 파일 | 행 수 | 한 행의 샘플 수 |
|---|---:|---:|
| TS1.txt | 2,205 | 60 |
| FS1.txt | 2,205 | 600 |
| PS1.txt | 2,205 | 6,000 |

모두60초 사이클입니다. 샘플 수가 다르다고 운전 시간이 다른 것은 아닙니다.

## S12 원본 위치에서 시간축으로

센서 → 파일 → 사이클의 행 → 행 안의 샘플

표시된 숫자를 원본에서 다시 찾을 위치를 확보했습니다.
