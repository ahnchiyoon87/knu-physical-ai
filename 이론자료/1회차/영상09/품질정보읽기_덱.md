# 관측의 품질 상태와 사용값 읽기

## S01 숫자를 받은 뒤 바로 사용해도 될까

관측을 다음 단계로 넘기기 전에 **사용 여부를 표시**합니다.

냉각 상태를 판단하려는 값에 누락·급변·반복이 있다면 먼저 확인해야 합니다.

이번 영상: 제공 검사기의 결과 읽기

다음 회차: 오류를 주입하고 품질 규칙을 바꾸며 비교하기

## S02 검사기는 두 항목을 더한다

| 항목 | 읽을 내용 |
|---|---|
| raw_value | 품질 검사에 들어온 값 |
| quality_flag | 제공 규칙이 붙인 품질 상태 |
| value | 이번 검사에서 사용하도록 남긴 값 |

앞에서 만든 관측에 **quality_flag·value**를 추가합니다.

## S03 OK이면 입력값을 사용값으로 남긴다

설명용 TS1 입력53.0 → 53.2를 제공 검사기로 실행한 결과입니다.

| raw_value | quality_flag | value |
|---:|---|---:|
| 53.2 | OK | 53.2 |

이번 검사에서는 **값을 바꾸지 않고 통과**시켰습니다.

## S04 값이 있어도 사용을 보류할 수 있다

별도 설명용 입력53.0 → 80.0의 결과입니다.

| raw_value | quality_flag | value |
|---:|---|---|
| 80.0 | SPIKE | None |

80.0은 **기록에 남고**, 사용값은 비워집니다.

## S05 비어 있는 칸과 0은 다르다

| 상태 | raw_value | value |
|---|---|---|
| 입력값이 없음 | None | None |
| 입력80.0의 사용을 보류 | 80.0 | None |

value가 비어 있을 때 **raw_value와 플래그를 함께 읽습니다.**

빈 값을0으로 채우면 새로운 측정값처럼 오해할 수 있습니다.

## S06 플래그는 보류한 이유를 구분한다

제공 검사기의 상태 이름입니다. 범위·횟수 기준은 교육용 설정입니다.

| 플래그 | 결과를 읽는 뜻 |
|---|---|
| OK | 현재 품질 규칙 통과 |
| MISSING | 입력값 누락 |
| GAP | 누락이 설정 기준 이상 이어짐 |
| SPIKE | 최근 기준값 대비 큰 변화 |
| STUCK | 같은 값이 설정 횟수 이상 반복 |
| OUT_OF_RANGE | 설정한 값 범위 이탈 |

## S07 현재 값만으로는 같은 결과가 나오지 않는다

별도 설명용 입력을 실제 검사기에 전달했습니다.

| 입력 이력 | 마지막 값 | 마지막 플래그 |
|---|---:|---|
| 53.0을 처음 입력 | 53.0 | OK |
| 53.0을8번 연속 입력 | 53.0 | STUCK |

품질 결과에는 **앞서 들어온 관측 이력**도 영향을 줍니다.

## S08 검사할 때 입력 순서를 확인한다

제공 check_many는 관측을 **ts·sensor_id 순서**로 정렬해 검사합니다.

센서별 상태는 **asset_id·sensor_id**로 구분합니다.

새 검사기를 만들면 이전 검사 이력이 이어지지 않습니다.

## S09 보류된 관측도 저장할 기록이다

```text
관측 → 품질 표시 추가 → 사용 여부와 원시 값 함께 보관
```

품질 검사는 보류된 행을 목록에서 삭제하지 않습니다.

설비·센서·시각·출처도 유지됩니다.

## S10 540개 OK로 어디까지 말할 수 있을까

원본 사이클100·101·102의 세 센서를 제공 코드로 검사했습니다.

**전체540개 / 품질OK 540개**

말할 수 있는 결과: 제공 센서 품질 규칙을 통과함.

이 결과만으로 확정할 수 없는 것: 설비 정상·냉각 성능 정상.

## S11 에이전트에게 처리 전후를 함께 요청한다

**요청 예시**

이번 실행의 센서별 품질 플래그 개수와 raw_value·value를 보여 주세요. 보류된 행이 있으면 입력값과 사용값을 비교하고, 원본 출처가 남아 있는지도 확인해 주세요.

비교 조건: **같은 입력·순서·검사 시작 상태·규칙**
