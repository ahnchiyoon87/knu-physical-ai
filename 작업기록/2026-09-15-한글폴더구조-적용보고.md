# 한글 폴더 구조 적용 완료

`D:/work/study/경남대 제조 피지컬 AI`를 새 작업 정본으로 만들고, 사용자 승인 구조에 맞춰 자료와 경로를 이관했다. 강의 내용 개편은 아직 진행 중이다.

| 대상 | 이전 | 적용 후 |
|---|---|---|
| 자료 위치 | 리뉴얼 안의 숫자 접두사 폴더 | 강의계획과운영·이론자료·실습자료·플랫폼코드·공용자료·제작도구·학생배포본·작업기록 |
| 1일차 실습 | 가이드와 출발본이 별도 이름으로 나열 | 실습자료/1일차 안의 가이드·시작코드 |
| 준비 검사 | 옛 경로와 일본어 결과 파일명 | 한글 구조에서 실행, 현재검증/준비검사.json·1일차_참고값.json |
| 재개 위치 | 기존 작업본 인계 | 강의계획과운영/인계.md. 기존 위치에는 안내 연결 |

| 확인 | 결과 |
|---|---|
| 복사·원본 보존 | 105개 파일 복사 직후 SHA256 일치, 원본 재확인 일치 |
| 주요 안내 링크 | 11개 대상 존재 확인 |
| 준비 검사 | 표본 27개, Python 50개 문법 확인, 정상 추출·덮어쓰기 거부·잘못된 입력 거부 통과 |
| 로컬 Compose | 새 플랫폼코드 위치에서 config --quiet 통과 |

플랫폼 내부 코드 구조와 기존 리뉴얼·대표님 원본은 보존했다. 원본 두 안내 파일에 새 위치를 연결하기 전 사본도 작업기록/이관전원본에 남겼다. 이론자료·공용자료·학생배포본은 아직 안내만 있으며 완성 자료가 아니다.

컨테이너 기동·모델 호출·실습 완주·UI 촬영·Git 연결은 하지 않았다. 원본과 새 정본이 함께 있으므로 앞으로 수정할 위치는 새 프로젝트 한 곳으로 고정한다.

근거: [이관 목록](자료이관_목록.json), [이관 검증](현재검증/이관검증.json), [준비 검사](현재검증/준비검사.json). 최종 구조는 [폴더구성](../강의계획과운영/폴더구성.md), 다음 작업은 [인계](../강의계획과운영/인계.md)를 따른다.
