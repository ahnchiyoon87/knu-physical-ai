# 제조 피지컬 AI 기반 개편 방향과 스킬 보강

대표님 교육용 플랫폼을 기반으로 **기본 스택의 이해·사용·응용을 거쳐 개인 산출물을 만드는 역량**에 강의의 초점을 다시 맞췄다. 제작 스킬 보강은 완료했으며, 강의 개편과 운영 환경 검증은 다음 작업이다.

## 왜 · 목적

기존 방향은 시스템을 처음부터 구현하고 기능을 쌓는 데 무게가 실려, 배운 기술을 활용하는 역량이라는 교육 목표에서 초점이 벗어났다. 대표님 구성을 기준으로 **스택의 역할을 이해하고 → 직접 사용해 사용법을 익히고 → PBL에서 이를 활용해 자신만의 산출물을 만드는 흐름**으로 바로잡았다.

학생에게 맨땅에서 플랫폼을 만드는 것을 요구하지 않는다. 제공된 플랫폼과 기본 스택을 출발점으로 삼아, 어떤 문제에 무엇을 연결하고 결과를 어떻게 확인할지 배우게 한다. 난이도 조절도 이 학습을 돕기 위한 수단이며, 개편의 핵심은 단순히 수업을 쉽게 만드는 것이 아니라 **학생이 배운 스택으로 스스로 무언가를 만들어낼 수 있게 하는 것**이다.

## 개편 방향

| 핵심 | 기존 방식·기준 | 적용할 방향 |
|---|---|---|
| 강의 기반 | 기존 엑셀 초안과 자체 어시스턴트 중심 | 대표님 실라버스와 교육용 플랫폼 중심. 센서 → 이상 감지 → 근거 조회 → 승인·조치 → 재측정의 흐름 유지 |
| 플랫폼·UI | 자체 화면을 중심으로 구현 | Process GPT·Ontology Studio·Data Fabric의 기능을 학습하도록 만든 **교육용 구현** 활용. 실제 상용 제품 전체와 구분하고 글자 크기·정보 배치·실행 결과의 가독성을 보강 |
| 학생 실습 | 대표님 자료의 코드·매핑 수정과 검사 | 바이브 코딩을 접목해 설치·코드 수정·MCP 설정을 코딩 에이전트에 요청. 학생은 요구·입력·성공 조건을 이해하고 화면과 근거로 결과 판단 |
| 응용 학습 | 시스템 구현과 제공된 실습 결과 완성에 무게 | 기본 스택의 역할과 사용법을 익힌 뒤, 개인 PBL에서 문제·요구·확인 기준을 정하고 같은 스택을 활용해 자기 산출물 제작. 짧은 명세와 결과를 비교하는 SDD로 이를 지원 |
| 운영 | 강사 서버·키를 사용하는 원본 안내, 개인 카드 등록을 전제한 기존 설치안 | 플랫폼·시뮬레이터·DB는 학생 PC에서 실행. 중앙은 LiteLLM으로 모델 호출·학생별 키·사용량을 관리하고 **코딩 기본 모델은 GPT-5.6 Luna로 계획** |

MCP는 AI가 외부 도구에 연결하는 규약이다. 설정은 에이전트가 수행하되 학생은 어떤 도구를 연결했고 무엇을 할 수 있는지 확인한다. 플랫폼 업무 에이전트의 도구 연결과 코딩 에이전트의 MCP 설정은 구별한다.

학교 일정·시수와 온라인 이론/오프라인 실습은 유지한다. 대표님 구성의 순서·스택을 바꾸거나 기존 제조 데이터를 섞는 구체안은 사용자와 협의한다. 로컬 운영은 중앙 실습 서버의 부담을 줄이는 대신 학생 PC 사양과 설치·복구 지원이 필요하다.

## 완료한 스킬 보강

대표님 `lecture-studio`의 강의·장면·음성 제작 방식을 검토해 기존 스킬에 반영했다.

| 대상 | 보강 내용 | 확인 결과 |
|---|---|---|
| STUDY 강의 스킬 5개 | 실라버스–학생 행동–결과 연결, 출처 확인, 초보자 개념·예시·복습, 슬라이드와 대본 연결 | 관련 진입점·참조 연결, 구조 검사 오류 0 |
| ROBO·STUDY 영상 스킬 | 클릭 후 실제 결과 표시 확인, 표시 시점에 음성 배치, 실패 장면만 재촬영하고 앞뒤 연결 재검사 | 시간 검사기 시험 각각 5개 통과, ROBO 구조 검사 오류 0 |

예: 결과가 화면에 나오기 전에 결과 설명이 시작하면 시간 검사에서 실패한다. 이 검사는 합성 기록으로 확인했으며 **실제 촬영 영상의 싱크·음성·가독성은 아직 검증하지 않았다.**

## 남은 작업과 근거

작업 자료는 STUDY의 기존 리뉴얼과 대표님 원본 두 폴더로 유지한다. 별도 프로젝트 분리는 최신 사용자 지시로 취소했다. 대표님 구성은 강의 제작에 활용하되 불필요한 폴더를 추가하지 않는다.

대표님 챕터를 학교 회차에 대응시킨 뒤 덱·온라인 대본·실습가이드·코드를 개편한다. 학생 PC 구동, 코딩 에이전트와 앱의 모델/임베딩 중계 호환성, 일차별 사용량을 확인해야 한다. **60명 비용은 미실측이며 확정하지 않았다.**
