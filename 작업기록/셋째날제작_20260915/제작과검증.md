## 실제 Neo4j Browser 화면

현재 로컬 Browser57474, DB접속57687에서 실제 읽기 질의3개를 실행했다. 유효 SOP→설비→센서 경로27개에서 고유 노드14개·관계15개, 모든 설비에 냉각 이상 SOP를 선택적으로 연결한 표8행, HYD-01 센서 식별자/코드/라벨 표3행을 확인했다. 전3장 확대 화면을 직접 검토하고 학생 가이드에 반영했다. 노드의 긴 이름은 Browser가 요약 표시하므로 정확한 ID는 별도 표에서 확인하게 했다.

최초 연결 직후 DB 선택·목록 로딩 전에 실행하면 No active database가 발생했다. 연결 문구만 기다리는 자동화를 DB준비 확인으로 고쳤다. 실패 화면은 내부에 보존하고 학생에게 정상 결과로 제공하지 않았다. 기존 데이터 초기화·시드 반복·승인·조치는 실행하지 않았다. 캡처 스크립트는 연결·읽기 질의·화면 확대만 수행한다.

READ_ACCESS 의심 Q07도 현재 환경에서 실제 거부(Neo.ClientError.Statement.AccessMode)와 전후 그래프 통계 동일을 확인했다. 공식 문서의 ‘권한 보장으로 사용하지 말 것’과 구분해 기록했다. 과제 동작은 변경하지 않았다.

근거: Browser실제화면/현재/조회기록.json 및 PNG3개, READ_ACCESS_현재환경확인.json. 최근 값 결합·사건 인용·잘못된 ID 되돌리기의 실제 화면은 아직 남았다. 이전 기능 검사와 새로운 Browser 화면을 학생 전체 완주로 합쳐 주장하지 않는다.
