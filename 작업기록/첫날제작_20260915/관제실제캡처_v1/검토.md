# 첫날 관제 실제 캡처

2026-09-15, 로컬 실행 중인 HydOps 관제를 별도 Playwright Chromium으로 열었다. CUA의 연결 브라우저가 없다는 사실을 전체 브라우저 캡처 불가능으로 확대하던 판단을 수정했다. 기존 브라우저 프로필이나 열린 편집 창은 사용하지 않았다.

- 도구: `제작도구/관제_읽기전용캡처.py`
- 실제 주소: `http://localhost:8800/`, HTTP200, 제목 `HydOps 관제 · B9`.
- 요청8개 모두 로컬 GET. 화면 편집·응답 대체·시나리오 주입·초기화·승인·조치를 하지 않았다. 브라우저 JS 오류0.
- 실제1536×864 캡처를 직접 확인했다. 한국어 제목·HYD-01·온도 그래프·교육용 합성 데이터·run_id가 보인다. 비밀키·사용자 계정 정보는 보이지 않는다.
- 현재 화면은 RUN-46b1c70b33이며 사건 목록은 비어 있다. 이 화면만으로 다른 run의 기존 승인대기 사건이 삭제되거나 종결됐다고 판단하지 않는다.
- 학생 가이드 1절에 원본 PNG를 그대로 복사하고 접속·관찰 위치·출처 설명을 넣었다. 값·시각·run 이름 일치를 성공 기준으로 강제하지 않는다.

한계: 관제 첫 화면 확인만 수행했다. 노트북 편집·원본 대조·DB 조회 동선의 UI 캡처와 학생 전체 완주는 아직 미완료다. 이미지 한 장을 첫 실습 흐름 전체의 완성으로 세지 않는다. 캡처 도구의 비허용 요청 차단 분기는 이번 모든 요청이 GET이어서 별도로 시험하지 않았다.
