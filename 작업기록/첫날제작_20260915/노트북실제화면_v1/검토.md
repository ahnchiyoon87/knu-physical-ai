# 노트북 실제 실행 화면

첫날 통합 완성본의 별도 복사본을 Jupyter nbconvert로 전 셀 실행했다. 관측_실행결과.ipynb에 실제 출력이 저장됐고 saved CSV540행을 다시 읽었다. 모델 호출·DB 변경은 하지 않았다. 이후 인증된 localhost:8889의 JupyterLab에서 실제 노트북을 열고 셀 영역을 캡처했다. DOM이나 출력값을 재작성하지 않았다.

원본_열수_v3.png, 관측_한값_v3.png, 저장_결과_v3.png를 직접 검토해 알림 겹침·잘림이 없음을 확인하고 가이드에 반영했다. 첫 화면의 첫 값은 사이클0이며 열 수 설명용이다. 사이클100의 원본 대조와 구분해 설명했다. 토큰·계정 정보는 캡처에 없다.

JupyterLab4.6.3 + Jupyter Server2.21.0 + Tornado6.5.9 조합에서 FileFindHandler가 allowed_symlink_directory를 초기화하지 않아 정적 JS 요청500이 발생했다. 검토 전용 설정은 선택된 정적 루트를 속성에 지정한 뒤 기존 검사를 호출한다. 일반 파일 반환과 바깥 파일을 가리키는 심볼릭 링크403을 실제 검사했다. 범용 호환 수정이나 학교 기본 IDE 확정으로 간주하지 않는다.

도구: Dockerfile.notebook-ui, 첫날_노트북화면준비.py, 노트북UI_호환설정.py, 첫날_노트북캡처.py. 검토 컨테이너 knu-notebook-review, 포트127.0.0.1:8889. 인증 토큰은 Git 제외 .runtime에 있으며 인계·가이드에 넣지 않는다. 사용자 작업 컨테이너는 종료하지 않았다.

남은 범위: 학생 시작본부터의 에이전트 수정 동선, UI에서 직접 셀 실행·저장·재개, 실전 DB조회 화면, 학생용 환경 안내 및 가이드 렌더. 실행 출력이 있는 노트북을 여는 것과 브라우저에서 전 실습을 완주하는 것은 다르다. 학생 전체 완주·비용은 사용자 담당이다.
