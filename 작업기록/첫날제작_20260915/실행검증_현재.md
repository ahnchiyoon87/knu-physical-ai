## 현재 검토 범위와 미완료

실제 관제1장, 노트북의 원본/관측/저장3장, DB조회·압력집계3장과 실제 재생 결과 그림1장을 가이드에 반영했다. JupyterLab에서 출력 저장된 노트북을 열고 내용을 확인했다. 실전조회 run LAB-S01-VIEW-86225428의540개 적재와 최근60초/사이클경계 결과는 노트북실제화면_v1/실전조회/조회결과.json에 있다. 이 조회 준비는 새 run을 추가했으며 기존 run을 삭제하는 명령은 수행하지 않았다.

현재 컨펌 입구는 강의계획과운영/첫컨펌_검토안내.md다. 학생의 코딩 에이전트 사용 완주·소요시간·비용·중앙 중계 호환성, 최종 설치 안내와 학생 ZIP, 온라인240분 전체 제작은 남았다. 사용자가 담당할 녹화와 실습 완주를 기능 검사로 대신하지 않는다.
