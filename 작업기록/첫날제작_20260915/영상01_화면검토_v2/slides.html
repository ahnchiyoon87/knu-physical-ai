품질OK는 제공 센서 품질 규칙을 통과했다는 뜻입니다. 설비 전체의 정상 판정은 아닙니다.

설비 관계와 적용 문서

관측의 설비 ID → 그 설비의 센서·허용 조치 → 적용되는 현행 SOP

SOP는 작업 절차를 담은 문서입니다. 온도가 비슷해도 다른 설비의 절차를 그대로 적용할 수는 없습니다.

파일 재생과 시뮬레이터

UCI 파일 재생교육용 합성 시뮬레이터
수집된 센서값을 다시 읽음프로그램의 상태로 새 값을 생성
원본 사이클·위치로 추적실행 ID·상태·조치 시점으로 추적
조치해도 과거 파일값은 바뀌지 않음구현된 조치가 이후 생성값에 영향을 줄 수 있음
읽기·집계·출처 추적을 확인승인·조치·재측정의 연결을 확인

시뮬레이터 결과는 해당 교육용 모델의 결과입니다. 실제 공장의 효과로 일반화하지 않습니다.
