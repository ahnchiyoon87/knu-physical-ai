# 영상02 제작 상태

## 현재 산출물과 범위

- `이론자료/1회차/영상02/센서값과단위_덱.md`: 12장면의 원천 텍스트.
- 같은 폴더 `센서값과단위_온라인대본.md`: 실제 읽을 설명 초안. 20분 목표이며 녹화 길이 미측정.
- `센서값과단위_화면초안.html`: 원천 텍스트에 설명용 도형을 붙인 화면. 제품 UI·실측 화면으로 꾸미지 않았다. PPTX 최종본은 아니다.
- S01~09 설명, S10 이해 확인 질문, S11 해설, S12 정리와 다음 영상 연결. 정식 퀴즈를 핵심 설명 사이에 끼워 넣은 구성이 아니다. ‘어느 설비인가’처럼 설명을 이어가는 질문과 구분한다.

## 이야기와 선수 개념

45(가정) → 측정 대상 → 단위 → 변환의 의미 → 어느 설비의 센서인가 → 여러 기록을 연결할 ID → 프로그램이 읽을 안내표 → 원본/설정/관측/화면 대조 → 요청 조건 → 이해 확인 → 원본 시점·사이클의 필요.

ID는 다른 화면의 기록을 같은 대상으로 연결할 필요를 설명한 뒤 소개했다. SENSOR_SPEC은 앞서 말로 확인한 파일·단위 약속을 프로그램에 알려줘야 한다는 필요에서 도입했다. 그래프 ID는 뒤 수업의 구현을 앞당기지 않고 관측의 두 필드와 다른 저장 약속을 소개하는 수준이다. 시각/사이클은 다음 편에서 설명한다.

## 사실 근거

- 제공 `실습자료/1일차/완성본/practical/mapping.py`의 SENSOR_SPEC: TS1/1Hz/°C, PS1/100Hz/bar, FS1/10Hz/L/min. AST로 실제 설정을 읽어 대응을 확인했다.
- `플랫폼코드/hydops/b4_ontology/graph.py`: 교육용 설비 이름과 ID, 센서의 code/quantity/unit/hz.
- 영상02는 원래 온라인1회차 구성표의 센서값·단위·ID·설정표 읽기 범위다. 리뉴얼의 미승인 M01을 도입한 것이 아니다.
- 예시45와 잘못된 단위·파일 연결은 설명용 가정이며 실측 사례로 쓰지 않는다.

## 검토와 미완료

v1은11장면, v2/v3은 질문과 해설을 분리한12장면이다. v1 전11장면을 모아보기로 검토했고 S07을 원본 크기로 확인했다. v2 질문·해설·다음영상3장면을 직접 열어 확인한 뒤 질문 카드의 단어 중간 줄바꿈을 v3에서 고쳤다. v3 내용대조·레이아웃 결과를 확인하고 이전과 같은 장면은 픽셀 해시로 대응한다.

HTML 텍스트·덱/대본 제목 대응과 시각 검토는 실제20분 분량·PPTX 렌더·학생 이해·첫 컨펌을 증명하지 않는다. 사용자 녹화와 컨펌 의견을 받아 분량과 표현·화면을 수정한다. 본문이 길다는 사실만으로20분을 충족했다고 계산하지 않는다.
