# 영상03 제작 상태

## 내용

`이론자료/1회차/영상03/센서파일과사이클_덱.md`와 `센서파일과사이클_온라인대본.md`를12장면으로 작성했다. 본문8743자이며 실제20분 분량은 아직 측정하지 않았다. PPTX·HTML 화면·녹화는 미제작이다.

영상02의 ‘어느 설비의 어떤 값인가’에서 ‘그 값을 원본에서 어떻게 찾는가’로 이어진다. 실제 TS1값53.219를 중심으로 센서/파일 → 반복운전/사이클 → 행/열 → 탭/줄바꿈 → 머리글 → 0부터세는인덱스 → 이웃행 비교 → 숫자형 → 제공읽기함수 → 센서별샘플수 → 다음영상 시간축을 설명했다. 같은 숫자60이 시간과 개수에 각각 쓰인다는 점을 따로 풀었다.

퀴즈를20분마다 의무 배치하는 계약은 없다. 영상02의 말미 질문은 현재 초안이며 전편 반복 규칙으로 확정하지 않았다. 영상03에는 본문과 예제 해설을 먼저 작성했고 별도 퀴즈 장면을 자동 추가하지 않았다. 영상당/주제묶음별 이해확인 빈도는 후속 구성 검토에서 다룬다.

## 근거와 실제 확인

- 원본 data/raw/description.txt는 행이사이클·열이사이클안의관측이며 탭구분,60초 반복,2205사례라고 설명한다.
- 세 파일의 전 행을 읽어 TS1은2205×60, FS1은2205×600, PS1은2205×6000임을 확인했다. 해시와 선택행 원값은 영상03_원본확인/원본확인.json에 있다.
- 제공 mapping.py read_raw_cycle을 네트워크 없는 실제 Python컨테이너에서 불러 실행했다. 세센서×사이클99/100/101의9개출력 전샘플이 독립 파일줄100/101/102와같았다. 코드·데이터 변경이나DB연결 없음. 읽기함수_대조.json이근거다.
- TS1의세행첫값53.324/53.219/53.379를덱과대본에반영했다.첫값만같을수도있어검사에서는전체행을대조했다.원본위치확인이필요한이유를설명하며정답숫자상수출력으로대체하지않는다.
- 덱·대본12개제목과순서대응확인.단순구조검사이며학생이해·녹화분량·화면가독성을증명하지않는다.

## 다음

실제 원본의 일부임을 밝힌 행/열 확대 그림, 파일 줄번호와 코드 인덱스를 연결하는 화면을 제작·검토한다. 원본파일의 전체샘플을그림에빽빽하게넣지않고 생략범위를표시한다. 이후 영상04측정주기·시간축으로 이어간다. 참고P01범위와기존영상구성표를유지하며미승인리뉴얼혼합M01은적용하지않는다.
