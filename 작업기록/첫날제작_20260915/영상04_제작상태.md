# 영상04 제작 상태

## 현재 산출물

- `이론자료/1회차/영상04/측정주기와시간축_덱.md`: 12장면.
- `측정주기와시간축_온라인대본.md`: 같은 제목·순서12절, 공백·제목 제외6,025자. 실제 낭독 시간은 미측정이다.
- `측정주기와시간축_화면초안.html`: 12장면 HTML 초안. PPTX와 사용자 녹화는 미완료다.

영상03의 ‘같은60초인데 개수는 다르다’를 받아 샘플 → 측정 빈도 → 간격 → 개수 검증 → 상대 시간 → 같은 위치/같은 시간의 차이 → 끝 경계 → 기록이 없는 시점 → 공통1초 구간 → 학생의 요구/판단으로 연결했다. 영상05의 구간 묶기와 영상06의 평균·범위 계산을 앞당겨 구현하지 않았다. 매편 퀴즈 의무 규칙을 추가하지 않았고 별도 퀴즈 장면은 없다. 사례를 함께 풀어가는 설명이다.

## 원문과 반영 범위

| 근거 | 확인한 사실 | 반영 |

첫 샘플을0초에 놓은 `인덱스/hz`는 알려진 빈도로 구성하는 **상대 시간 좌표**다. 원본에 샘플별 절대시각이 있는 것처럼 설명하지 않는다. 정밀 센서 동기화 오차를 검증했다는 주장도 하지 않는다. 간격이 일정하다는 전제로 위치를 대응시키며, 비정수 위치에 원본 샘플이 없다는 설명은 원본 결측 판정과 구분했다. 새로운 보간 알고리즘·스택·리뉴얼 자료 혼합은 없다.

## 실제 실행 확인

`제작도구/영상04_시간축확인.py`를 기존 수업 검토 이미지 `knu-hydops-notebook-ui:review`에서 실행했다. 네트워크 없음, 프로젝트 읽기전용 마운트, 증거 폴더만 쓰기 허용. DB와 유료 API를 호출하지 않았다.

세 센서의 사이클100을 제공 함수로 읽어 독립적인 파일101번째 줄의 전체 숫자와 대조했다. 상대 시간은 Fraction으로 계산하여 소수 경계 반올림을 피했다. 각 센서의60구간에 모든 샘플이 중복·누락 없이 들어갔고, 구간별 mean/min/max/n이 과제 함수 및 공통 플랫폼 함수와 모두 일치했다. 원본 샘플의 마지막을60초에 억지로 놓은 축은 지정 측정 간격과 맞지 않음을 확인했다. 근거는 `영상04_시간축확인/시간축_대조.json`이다.

| 확인 항목 | TS1 | FS1 | PS1 |
|---|---:|---:|---:|
| 인덱스10의 상대 초 | 10 | 1 | 0.1 |
| 10초의 인덱스 | 10 | 100 | 1,000 |
| 마지막 상대 초 | 59 | 59.9 | 59.99 |
| 10.05초에 원본 샘플 존재 | 아니요 | 아니요 | 예 |
| 10초 이상11초 미만의 인덱스 | 10 | 100~109 | 1,000~1,099 |

## 화면과 내용 검토

`영상04_화면검토_v1`에 전12장 PNG와 렌더검사.json을 저장했다. 전 장을 네 장씩 모아 직접 열어 읽기·겹침·잘림을 검토했다. S03의 두 시간축은1Hz와10Hz를 비교하는 예이며100Hz의 개수는 옆 표에 명시했다. S07은 같은10초 눈금 위에 서로 다른 시점을, S08은 그 눈금 위의 같은 시점을 표시한다. 도형은 설명용이며 실제 UI 캡처가 아니다.

덱·대본12개 제목 대응과 HTML의 전체 본문 일치를 확인했다. 인덱스1,000을100으로 바꾼 본문은 비교에서 일치하지 않는다. 이는 구조와 내용 보존 검증이며 학생 이해·실제20분을 보증하지 않는다.
