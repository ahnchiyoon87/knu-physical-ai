# 영상06 제작 상태

## 산출물과 설명 흐름

`이론자료/1회차/영상06`에 `첫값과평균범위_덱.md`·`첫값과평균범위_온라인대본.md`·`첫값과평균범위_화면초안.html`을12장면으로 제작했다. 대본은 제목·공백 제외4,971자다. `그림/압력_첫1초.png`와 같은 내용의 SVG는 실제 제공 데이터100개를 그린 그래프이며 제품 UI 캡처가 아니다.

영상05의 첫1초 묶음 → 실제100개 변화 → 시작본 첫 값 선택 → 평균 계산 → 첫 값과 평균의 질문 차이 → 최소/최대 → n → 요약에서 사라지는 순서 → 원본 추적 → 세 센서 비교 → 결과 검토 → 영상07 관측 레코드로 이어진다. 기존 원문 P01 활동2를 설명하는 범위이며 신규 스택·리뉴얼 혼합·시간 재배분·의무 퀴즈는 없다.

## 원문과 수치

참고 `textbooks/실전반/P01_첫_데이터가_흐르는_시스템.md` 활동2의 첫 샘플/평균 비교, 현재 과제의 시작본·완성본 `reduce_to_seconds`, 첫날 실습가이드3~4절과 연결된다. 값은 원본 파일101번째 줄의 첫Hz개에서 다시 계산했다.

| 센서 | 첫 값 | 평균 | 최소 | 최대 | n |
|---|---:|---:|---:|---:|---:|
| TS1 | 53.219 | 53.219 | 53.219 | 53.219 | 1 |
| FS1 | 7.653 | 0.9028 | 0 | 7.653 | 10 |
| PS1 | 147.21 | 170.1621 | 141.27 | 189.88 | 100 |

PS1 합계17,016.21, 평균과첫값차이22.9521, 관측범위폭48.61이다. Decimal로 원본 소수를 계산하고 제공 함수의 부동소수 결과와 절대오차1e-10 이내로 대조했다. 화면의 반올림과 실제 계산을 구분한다. 첫 값보다 평균이 항상 크다는 규칙을 만들지 않았으며 FS1의 반대 사례를 설명했다.

## 의미상 주의와 실행 근거

- 시작본의 `mean`이라는 이름은 실제 평균 계산을 보증하지 않는다. 첫 샘플 자체가 잘못된 값이라는 설명도 하지 않는다.
- 최소·최대는 관측 범위이며 안전 기준이 아니다. n은 사용 개수이며 품질·설비 정상을 보증하지 않는다.
- `[1,3,2,4]`와 `[4,2,3,1]`은 요약의 정보 손실을 설명하는 명시적 가정 예시다. 평균2.5·최소1·최대4·n4가 같지만 순서는 다르다. 실제 측정값으로 표시하지 않았다.
- 원본 파일·센서·사이클·구간·빈도를 보존해야 세부 순서를 다시 읽을 수 있다. 원본 추적을 요약 통계만으로 복원하는 것과 구분했다.
- 원본 그래프는 시작 부근에서 내려간 뒤 전반적으로 상승한다. 평균선은 시간에 따른 실제 값이 아니라 구간 전체의 요약선이다. 선으로 연결한 지점을 모두 측정점으로 오해하지 않도록 설명했다.

`제작도구/영상06_통계와그림.py`는 원본에서 독립 계산 → 제공 시작본/완성본 호출 → 실제 그래프 생성까지 수행한다. 기존 검토 이미지 `knu-hydops-notebook-ui:review`에서 네트워크 없음, 프로젝트/한글 글꼴 읽기전용 마운트, 증거 폴더만 쓰기 허용으로 실행했다. DB·유료 API 호출 없음. `영상06_재현확인`의 새로운 폴더에서 실행해 원본 JSON·함수 대조 JSON·그래프 PNG가 이전 결과와 같음을 확인했다. 재현대조.json에 범위를 기록했다. SVG는 생성 식별자 차이가 있을 수 있어 바이트 일치 검사를 하지 않았다.

## 화면 검토

그래프 첫 출력에서 최소값 주석과 범례가 겹쳐 범례를 왼쪽 위로 옮겼다. 이전 그림은 통계확인/그림_v1에 보존했다. S02는 실제 그래프를 큰 화면으로 배치했다. HTML 검사의 숨겨진 빈 측면 영역 오탐은 표시 크기가0인 요소를 구분하고 실제 img·figcaption을 검사하도록 고쳤다.

HTML v2 전12장면을 모아보기로 확인하고 S02는 원본 크기로 확인했다. v3는 S12의 한 글자 줄바꿈을 수정했으며 해당 장면을 원본 크기로 확인했다. S01~11은 v2와 PNG 해시가 같다. 덱·대본12개 제목 대응, HTML 본문 전체 일치, 평균을첫값으로 바꾼 본문의 불일치를 확인했다. 근거는 영상06_화면검토_v3/렌더검사.json 및 영상06_재현확인/재현대조.json이다.
