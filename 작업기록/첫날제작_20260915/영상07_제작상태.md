`이론자료/1회차/영상07/관측레코드와출처_덱.md`·`관측레코드와출처_온라인대본.md`·`관측레코드와출처_화면초안.html`을12장면으로 제작했다. 대본은 제목·공백 제외5,140자다. 실제20분 분량·PPTX·사용자 녹화는 미완료다.

영상06의 평균값 → 해석 정보 필요 → 레코드/필드 → 설비/센서 → 값/단위 → 원본 위치 → 집계 → None → 합성 구분 → 딕셔너리 →180개 → 함수 입력/결과 → 재생 시각으로 연결했다. 실제 코드9필드 모두를 설명하며 한 장에 전부 나열하는 대신 필요한 질문 순서로 도입했다. 다음 영상08에서 재생 시각과 실행 구분을 이어간다.

## 근거와 설명 경계

- 참고 P01의 공통 관측 레코드 설명, 현재 `실습자료/1일차/완성본/practical/mapping.py`의 map_cycle, `플랫폼코드/hydops/b1_data/uci.py`의 cycle_observations를 확인했다. 같은 필드·출처·집계 방향이며 원문 스택·순서·필수 활동·시간 배분을 변경하지 않았다.
- HYD-01은 수업 함수에 지정하는 설비ID다. 원본 파일에서 읽은 실제 실험장비 고유번호로 설명하지 않는다.
- 이 매핑 단계의 raw_value는1초 평균이다. 원본 첫 샘플이나 품질 처리 이후의 최종 사용값과 혼동하지 않는다.
- TS1의 agg=None은 이 형식에서 집계 묶음을 생략한 것이며 온도값 결측이 아니다. is_synthetic=False는 UCI 원본 재생 경로의 구분으로, 가공하지 않았거나 현재 실시간 수집 중이라는 뜻은 아니다.
- 원본6,660샘플과 결과180레코드를 구분했다. 한 레코드는 센서 하나의1초 관측이므로 같은 elapsed_s에 서로 다른 센서3개의 레코드가 생긴다.
- map_cycle은 품질검사·DB적재·UI갱신을 수행하지 않는다. 현재 결과9필드에 품질 플래그나run_id를 이미 포함한 것처럼 만들지 않았다. ts의 기준은 짧게 소개하고 자세한 재생/실행 설명은 다음 편에 둔다.

## 실제 실행과 대조

`제작도구/영상07_관측확인.py`를 기존 검토 이미지에서 네트워크 없이 실행했다. 프로젝트 읽기전용 마운트, 증거 폴더만 쓰기 허용. DB·유료 API 호출 없음.

실제 read_raw_cycle로 TS1·PS1·FS1의 사이클100을 읽고, 실제 map_cycle에 HYD-01과 제공 LAB_REPLAY_START를 전달했다. 원본 파일101번째 줄을 독립적으로 읽어 모든60구간의 통계를 Decimal로 계산했다. 결과180개 각각의 평균·단위·원본사이클·경과초·재생시각·집계·합성여부를 대조했다. 부동소수 평균의 비교 허용 오차는1e-10이며 원본/단위/정수 항목은 동일해야 한다.

결과는 센서별60개, 전체180개, 필드9개다. 단위 누락·잘못된 단위·잘못된 사이클·합성여부 변경·평균 대신 첫값·시각1초 이동·집계 누락의7개 변조 입력을 모두 거부했다. 실제 관측 전체는 `영상07_관측확인/관측.json`, 범위·선택관측·코드 해시는 대조.json에 있다. 이 기록은 학생 전체 완주나DB저장 검증이 아니다.

## 화면 검토와 남은 일

`영상07_화면검토_v1`의 전12장면을 네 장씩 모아 직접 확인했다. 본문과 필드명의 잘림·겹침은 보이지 않았다. 도형은 설명용 관측 구조이며 실제 UI 캡처가 아니다. 덱·대본의12개 제목 대응과 HTML 전체 본문 일치를 확인했고, 평균을 첫 값으로 바꾼 본문은 불일치로 검출됐다. 내용 보존 검사는 학생 이해나실제 영상 분량을 증명하지 않는다.

다음은 영상08의 세 사이클 재생·시각 경계·run_id 구분이다. 이번180개를 실제저장540개와 무리 없이 연결하되 실행 구분이 없는 변환 결과와 저장 결과의 차이를 설명한다. 후속 PPTX는 첫 컨펌 의견을 반영하며, 전체 강의·합류 배포본·중계 호환·사용자 완주·비용은 계속 미완료로 추적한다. M01 혼합 의견 대기도 유지한다.
