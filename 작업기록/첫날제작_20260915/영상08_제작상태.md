# 영상08 제작 상태

## 현재 산출물과 확인

- 재생시각과실행 덱·온라인대본·HTML 12장면. 덱/대본 제목 전체 일치. 대본 본문 공백 제외 4,330자이며 실제 발화 길이는 미측정이다.
- 실제 map_cycle로 원본100·101·102의 관측540개를 생성한 기존 실행 근거를 대조했다. 센서별180개, 재생 경계와 원본 경과초 리셋, 시작1시간 이동 후 시각 이외 필드 동일을 확인했다. 잘못된 시간/출처 세 경우를 거부한 근거는 영상08_재생확인/재생대조.json이다.
- load_cycles 전체 재실행이나 새 DB적재를 했다는 뜻은 아니다. 기존 LAB-S01-VIEW-86225428의 읽기 전용 조회는 별도 근거 영상08_재생확인/기존저장본_조회.json에 있다.
- run_id를 전달해 관측을 저장하는 코드와 DB 스키마를 대조했다. 실행 이름이 자동 중복 제거/교체를 보장한다고 가르치지 않는다. LAB-DEMO-A/B는 설명용 예시다.
- HTML v1 전12장면 모아보기 직접 검토. v2에서는 서로 다른 식별자나 비교 대상을 처리 순서처럼 보이게 하는 화살표를 S03/06/08/09/11에서 제거했다. 수정5장 직접 검토, 나머지7장 PNG는 v1과 바이트 동일이다. v2 전12장 본문대조·경계검사 통과, 540→541 본문 변조 대조 거부.

## 내용의 진전과 반복 위험

사용자 반복 금지 지시에 따라 영상08 S02/S06의 앞 영상 재설명을 짧은 상기로 줄였다. 근거 영상08_반복검토.md. 덱의 수치·요약과 장면 대응은 유지했다.

영상04는 한 사이클 안에서 센서별 인덱스를 상대 초로 읽는 내용, 영상07은 관측 하나에 원본 정보를 붙이는 내용이다. 이번 영상08은 여러 사이클의 연속 시각과 사이클 안의 위치가 서로 다르게 움직이는 이유, 동일 원본 재실행을 run_id로 구분하는 판단을 더한다. 이전 센서·요약 설명은 도입에서 상기하고 다시 전개하지 않았다.

사용자 전체 주제 질문에 답하며 발견한 교육적 의심: 영상02~08 목표140분은 기초 데이터 설명이 지나치게 잘게 나뉠 위험이 있다. 주제 중복이 실제로 확정됐다는 뜻은 아니다. 각 편의 새 판단과 설명 분량, 영상09~12의 품질·DB·조회·SDD에 필요한 깊이를 함께 검토해야 한다. 12개 파일이나 장수로240분 충족을 주장하지 않는다. 시간 재배분은 적용하지 않았으며 필요하면 원래 구성·근거·변경표·영향을 사용자에게 제안한다.
