# 영상11 제작 상태

## 산출물과 새 설명

실행과구간조회 덱·대본·HTML12장면 제작. 대본 본문 공백 제외3,300자, 장면 제목12개 대응. 실제20분·PPTX·녹화·컨펌은 미완료다.

새 설명은 SELECT/FROM/WHERE, AND 조건, 제공 Psycopg의%s값전달, ORDER BY, 최근구간의기준시각, until, 조회경계, 실행조건누락과빈결과다. 기존 평균·레코드·재생 원리·저장 절차는 다시 전개하지 않았다. 표의숫자만읽는것으로끝내지않고학생이요청한조건과반환행의실행·시각·출처를대조하도록연결했다.

## 실제 조회 근거

현재 b3_tsdb/store.py의 recent_window를 읽고 전용 hydops_v10_review DB에서 직접 호출했다. 영상10의 LAB-V10-STORAGE540개를 기준으로 사용했다. 원본100·101·102를1시간뒤시각으로재생한 LAB-V11-OTHER540개를 같은 검토DB에 추가했다. 원본 저장소·공통 코드·기존 운영DB·다른앱은 변경하지 않았다.

- 내 실행 기본 최근구간:00:02:00~00:02:59, 전체180행, PS1만60행, 원본102.
- until=00:01:30:00:00:31~00:01:30, 원본100에서87행/101에서93행. 센서별29+31=60.
- 존재하지 않는 실행:0행.
- 실행 조건 없음:더늦게재생한 다른 실행의01:02:00~01:02:59를180행조회.
- 시작비교를>=로바꾼별도읽기전용SQL:183행. 제공함수의180행과차이확인.
- 제공함수의결과를원래저장된전체행에서독립적으로선택한기대행과대조했다. 기준실행540개전후SHA256동일.

근거 제작도구/영상11_조회확인.py와 영상11_조회확인/조회대조.json. 이 도구는 비교실행을추가하므로읽기전용도구라고하지않는다. 이미다른실행이있으면재적재하지않고중단하도록했다. 같은 검토DB에는 이제두실행총1080개가있으며 기존실행은540개로유지된다.

## 의미·렌더 검토

기본끝시각은시스템현재시각이아니라설비와선택한실행의max(ts)다. sensor_id는끝시각탐색의조건이아니고이후행선택에적용된다는실제코드를반영했다. 끝경계포함조회와원본샘플을1초로묶는구간경계를같은연산처럼설명하지않는다.

HTML전12본문MD대조와경계검사통과,183→184변조불일치검출. 전12장면모아보기3장직접검토,제목·표·본문잘림/겹침은보이지않았다. 개념도는설명용조회구조이며실제UI캡처로표시하지않는다. 문장띄어쓰기는대본후반을수정해읽을수있는형태로검토했다.
