# 첫 컨펌 단위 제작 상태

사용자 최신 기준은 온라인 회차 영상240분·편당최대20분, 영상+PPTX 단위 컨펌이다. 시간 배분을 다시 협상하거나 이론과오프라인을일차별세트로 강제하지 않는다.

## 현재 산출물

- `강의계획과운영/온라인1회차_영상구성.md`: 실V1의12편 목표·각20분·합계240분, 첫편11장면 합계20분 목표. 실제 재생시간 아님.
- `이론자료/1회차/영상01/제조데이터와판단_덱.md`: 첫 영상의11개 장면에 들어갈 설명·비교·이해 확인. 개념도와 설명용 예시는 실제 UI가 아니다. HTML 및 실제 PowerPoint 렌더 확인. 영상은 미완료.
- `이론자료/1회차/영상01/제조데이터와판단.pptx`: 11장 검토용 PPTX. 텍스트·도형을 편집할 수 있고 표 셀은 개별 텍스트 상자다. PowerPoint의 표 객체는 아니다. 영상용 최종 화면 구성 및 컨펌은 남았다.
- `이론자료/1회차/영상01/제조데이터와판단_온라인대본.md`: 실제 읽을 대본11절 작성. 덱 제목과순서11개 일치 확인. 제목 제외 공백/개행 포함8149자. 문자 수를 재생시간으로 환산해 통과 처리하지 않았다. 음성은 미생성·미측정이다.

## 근거

기존 P01 교재, P01/I01 자막, 영상 README/SPEC_GUIDE, 프로젝트 관측과출처17장 및 실제첫날검사기록을 확인했다. P01 자막은기초·함수풀이·시험실행·요약까지포함하고 I01도노트북과제풀이를포함한다. 대표님 영상의26:43/13:21을4시간온라인이론으로간주하지 않는다. 첫 영상은P01의시스템위치·관측출처 도입을학생판단관점에서설명한다. 고급스택의상세구현순서를앞당기지않는다.

## 제작 도구 상태

Presentations 지정 런타임은 메타데이터만 있고 패키지와 로더가 없어 사용하지 못했다. 이를 PPTX 제작 전체의 차단으로 취급하던 판단을 수정했다. STUDY의 기존 `lecture-deck/덱pptx.py`로 제작하고 `제작도구/PPTX_화면확인.ps1`로 실제 PowerPoint에서 렌더했다. 지정 런타임 검증을 통과했다는 뜻은 아니다. 빌더의 프로젝트 루트 탐지 경고가 있어 자동 잠금 검사를 통과했다고 주장하지 않는다. 기존 손질본을 덮지 않고 새 작업 경로에서 제작했다.

사용자가 마이크로 직접 강의하고 녹화한다고 확정했다. 이전 AI 음성 선호 질문은 해소됐으며 다시 묻지 않는다. 에이전트의 제작 범위는 녹화용 PPTX·온라인 대본·구성표와 별도의 실습가이드다. TTS·영상 합성을 진행하지 않는다. 녹화·외부 제출은 사용자 담당이고, 녹화 뒤 실제 분량과 컨펌 의견을 반영한다.

## 다음 작업

### 화면 미리보기 실제 검토

`제작도구/이론화면_미리보기.py`로 첫 덱을1600×900 HTML11장과PNG로 렌더했다. PowerPoint나수업앱을캡처한것이아니다. 첫버전S02/S05/S07/S08의여백영역초과를확인해셀안여백과마지막문단여백을수정했다. v3 전11장실물확인에서퀴즈3문항이한문단으로붙는변환결함을찾아수정했다. v4 S09를직접다시확인했고나머지10장PNG는v3와해시가같다. v4영역검사11장오류0. 이미지글자가한국어로표시되고내용잘림없음을확인했지만PPTX렌더/영상동작검증은아니다.

현재 HTML 입력은 `영상01_화면검토_v5/slides.html`이다. 빌더가 section을 flex로 바꿀 때 가로 배치되던 문제를 HTML의 세로 방향·크기 유지 지정으로 고쳤다. 실패한 PPTX v1은 내부에 보존하고 배포하지 않는다. v4는 이전 HTML 미리보기다.

현재 PPTX 검토 근거는 `영상01_PPTX검토_v2/렌더/슬라이드1.PNG`~`슬라이드11.PNG`와 `내용대조.json`이다. 이전 턴에서1~4장을 확인했고 이번 턴에서5~11장을 직접 확인했다. 텍스트 잘림·겹침은 발견하지 못했다. 원문 MD와 전11장 텍스트의 순서·내용이 일치한다(공백·Markdown 표기 정규화). 각 장 한 글자 누락 반증도11/11 탐지했다. 전 장에 편집 가능한 텍스트가 있으며 통이미지 슬라이드는 없다.

품질 보강은 남았다. 일부 표의 한국어 단어가 줄 사이에서 갈라지고 표 구분선에 그림자가 붙는다. 전체적으로 표가 많고 첫 장의 전체 흐름은 한 줄이므로, 영상에서는 흐름의 시각적 배치와 발화에 맞는 단계별 표시를 보강한다. 내용 보존·렌더 확인을 최종 영상 품질이나20분 충족으로 세지 않는다.

PPTX와 대본의 대응 및 설명 흐름을 보강해 사용자가 녹화할 수 있게 준비한다. 장면별 목표 시간은 예상이며, 사용자 녹화 후 실제 분량을 확인한다.20분 상한을 맞추려 말을 빠르게 하거나 장면을 생략하지 않는다. 분할이 필요하면 다음 편과의 경계를 명시해 누락을 막는다. 첫 단위 컨펌 전 나머지 영상의 일괄 제작은 하지 않는다.
