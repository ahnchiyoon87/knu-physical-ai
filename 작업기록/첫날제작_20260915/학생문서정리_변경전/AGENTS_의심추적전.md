# 플랫폼 기반 개편 작업 지침

상위 STUDY 계약과 최신 사용자 지시를 따른다. 현재 상태는 `강의계획과운영/인계.md`에서 확인한다.

최신 필수: 대표님 자료는 현재 우리 자료보다 흐름이 나은 주된 참고 토대이며 완벽한 정본으로 맹신하지 않는다. 두 자료의 장점을 합치는 것이 방향이다. 기존 리뉴얼 자료·기법을 혼합할 지점에서는 바로 이유·변경 내용·영향을 제시하고 의견을 받은 뒤 적용한다. 오류 의심은 문맥·코드·데이터를 꼼꼼히 검증하고 단정하지 않는다. 이미 합의한 AI 코딩·학생 판단 방식의 제작은 바로 진행하며 대응표 전체 재승인을 관문으로 만들지 않는다. 자체9단계 초안도 확정본이 아니다. 고가 모델 사용은 허용됐으며 비용 실측은 사용자가 수행한다.

- 대표님 플랫폼·냉각 이상 대응 시나리오가 토대다. 비전공자용 학습 흐름은 다시 설계한다.
- 설치·MCP 설정·코드 작성은 코딩 에이전트가 수행한다. 학생은 목적·요구·결과를 이해하고 판단한다.
- 처음에는 명세와 요청 예시를 주고 점차 도움을 줄인다. 개인 PBL은 익숙한 스택의 전이·확장으로 만든다.
- 날짜·시수·반 구성은 고정. 두 반의 핵심 내용은 같고 대본은 온라인 이론에만 둔다.
- 학생별 로컬 실행 + 중앙 모델 중계가 기본 운영 방향이다. 유료 호출·비용 측정은 사용자가 수행한다.
- 기존 리뉴얼과 대표님 클론은 원본으로 보존한다. 여기의 수정본만 개편한다.
- 고급 기법은 설치 난이도로 일괄 제외하지 않는다. 해결할 문제·쉽게 관찰할 효과·호출 비용을 보고 선별한다.
- 문법 검사·제공자의 캡처를 이번 실제 완주 증거로 표시하지 않는다. 실측하지 않은 시간·비용·최소 사양을 확정하지 않는다.
- `.env`, 인증정보, 로컬 DB, 생성된 개인 결과는 Git과 학생 ZIP에서 제외한다.

## 자료 위치

사용자가 승인한 한글 폴더 구조를 유지한다. 구조 안내는 README.md를 따른다. 새 작업 정본은 이 프로젝트이며 기존 리뉴얼의 플랫폼기반_개편을 동시에 수정하지 않는다. 폴더 번호는 붙이지 않고 회차에만 1일차처럼 숫자를 쓴다. 코드 내부 영문 구조는 유지한다. 이론자료와 학생배포본의 빈 상태를 강의 완료로 세지 않는다.
